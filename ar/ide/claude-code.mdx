Claude Code هو مساعد الذكاء الاصطناعي لسطر الأوامر من Anthropic. بعد تثبيت OpenYida، ما عليك سوى التحدث مع الذكاء الاصطناعي وسيقوم تلقائياً باستدعاء جميع الأوامر لإكمال بناء التطبيق.

---

## الإعداد لمرة واحدة

العملية بأكملها تحتاج خطوتين فقط، بعدها كل شيء يتم عبر المحادثة.

<Steps>
  <Step title="تثبيت OpenYida">
    تأكد من وجود [Node.js ≥ 18](https://nodejs.org)، ثم شغّل في الطرفية:

    ```bash
    npm install -g openyida
    ```

    بعد التثبيت، يتم حقن حزمة مهارات OpenYida تلقائياً في Claude Code، دون الحاجة لأي تهيئة إضافية.
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    شغّل Claude Code وقل مباشرة:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```

    سيستدعي الذكاء الاصطناعي أمر تسجيل الدخول تلقائياً، ويفتح المتصفح أو يعرض رمز QR للمسح. بعد تسجيل الدخول الأول، يتم تخزين بيانات الاعتماد مؤقتاً ولا حاجة لتكرار العملية.
  </Step>
</Steps>

<Tip>
  هذا كل شيء، الإعداد اكتمل. من الآن فصاعداً، ما عليك سوى التحدث مع الذكاء الاصطناعي.
</Tip>

## اختيار النموذج

يستخدم Claude Code نماذج سلسلة Claude افتراضياً، يمكنك التبديل عبر أمر `/model`:

| النموذج | السيناريو الموصى به |
|---------|---------------------|
| **Claude Sonnet 4** (افتراضي) | بناء التطبيقات اليومي، سريع |
| **Claude Opus 4** | أنظمة معقدة متعددة النماذج |

كلاهما يعمل بشكل ممتاز مع OpenYida. للاستخدام اليومي، Sonnet كافٍ.

---

## ابدأ البناء

صف مباشرة بلغة طبيعية التطبيق الذي تريده، وسيتولى الذكاء الاصطناعي كل شيء تلقائياً:

```
ساعدني في إنشاء نظام CRM على Yida، يشمل:
- نموذج العملاء المحتملين: الاسم، الشركة، الهاتف، المصدر، الحالة
- نموذج العملاء: اسم الشركة، القطاع، جهة الاتصال، مدير الحساب
- نموذج الفرص: عميل مرتبط، المبلغ، المرحلة، تاريخ الإغلاق المتوقع
```

```
أنشئ تطبيق إدارة أصول تقنية المعلومات، لتسجيل معلومات الأجهزة وتتبع الاستعارة والإرجاع
```

```
انشر هذه الصفحة واجعلها متاحة للوصول العام
```

سيكمل الذكاء الاصطناعي تلقائياً جميع الخطوات مثل إنشاء التطبيق والنماذج ونشر الصفحات. لا تحتاج لحفظ أي أوامر.

## مثال محادثة فعلي

فيما يلي تدفق محادثة نموذجي:

> **أنت**: ساعدني في إنشاء نظام إجازات الموظفين
>
> **الذكاء الاصطناعي**: حسناً، سأساعدك في الإنشاء. دعني أتحقق من البيئة وحالة تسجيل الدخول...
>
> البيئة سليمة، تم تسجيل الدخول. سأبدأ الآن بإنشاء التطبيق...
>
> تم إنشاء نظام الإجازات بنجاح! يتضمن:
> - نموذج طلب الإجازة (مقدم الطلب، نوع الإجازة، تاريخ البداية/النهاية، السبب)
> - رابط التطبيق: https://www.aliwork.com/APP_XXXXX/...
>
> هل تريد مني إضافة عملية موافقة؟

ما عليك سوى ذكر متطلباتك، والذكاء الاصطناعي يتولى التنفيذ.

## الاستخدام المتقدم

عندما تصبح أكثر إلماماً، يمكنك إعطاء الذكاء الاصطناعي تعليمات أكثر دقة:

```
احصل على قائمة حقول نموذج "معلومات العملاء"، أريد التأكد من تهيئة الحقول
```

```
ساعدني في إنشاء موصّل Yida من أمر curl هذا:
curl -H "Authorization: Bearer xxx" https://api.example.com/users
```

```
تحقق مما إذا كانت هناك مشكلة في البيئة
```

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="الذكاء الاصطناعي يقول لم يجد أمر openyida">
    تأكد من نجاح التثبيت في الطرفية: `openyida --version`. إذا كان مثبتاً لكن Claude Code لا يجده، اخرج وأعد تشغيل Claude Code.
  </Accordion>

  <Accordion title="ماذا أفعل عند انتهاء صلاحية تسجيل الدخول">
    قل مباشرة للذكاء الاصطناعي "سجل الدخول مجدداً إلى Yida"، وسيتعامل مع الأمر تلقائياً.
  </Accordion>

  <Accordion title="الذكاء الاصطناعي لا يستخدم مهارات OpenYida">
    اذكر كلمة "Yida" في المحادثة للتفعيل. مثال: "أنشئ نموذجاً على Yida".
  </Accordion>

  <Accordion title="أريد التحديث لأحدث إصدار">
    قل للذكاء الاصطناعي "ساعدني في تحديث openyida" أو شغّل يدوياً `npm install -g openyida@latest`.
  </Accordion>
</AccordionGroup>
