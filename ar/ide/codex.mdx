Codex هو بيئة البرمجة بالذكاء الاصطناعي من OpenAI. يتمتع OpenYida بـ**تكامل أصلي على مستوى الإضافات** مع Codex — بعد التثبيت، يتم تسجيله تلقائياً كإضافة محلية في Codex، ويظهر مباشرة في قائمة `@` كخيار "Yida"، مع خادم MCP مدمج يوفر قدرة استدعاء الأدوات. هذا هو أعمق تكامل بين جميع بيئات التطوير المدعومة.

---

## الإعداد لمرة واحدة

<Steps>
  <Step title="تثبيت OpenYida">
    تأكد من وجود [Node.js ≥ 18](https://nodejs.org)، ثم قم بتشغيل:

    ```bash
    npm install -g openyida
    ```

    بعد التثبيت، يتم تلقائياً:
    - تسجيل OpenYida كإضافة محلية في Codex (يظهر في قائمة `@`)
    - تهيئة خادم MCP (يمكن للذكاء الاصطناعي استدعاء أدوات Yida مباشرة)
    - حقن حزمة المهارات الكاملة
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    افتح Codex وقل مباشرة:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```

    سيفتح الذكاء الاصطناعي المتصفح المحلي لإكمال تسجيل الدخول. إذا كنت تنتمي لعدة مؤسسات، سيعرض Codex عنصر تحكم اختيار أصلي لتختار منه.
  </Step>
</Steps>

<Tip>
  بعد التثبيت يصبح جاهزاً للاستخدام. OpenYida هو "مواطن من الدرجة الأولى" في Codex — لا تحتاج حتى لمعرفة وجود واجهة سطر الأوامر.
</Tip>

## طريقة الاستخدام

### الطريقة 1: قائمة @ (موصى بها)

في مربع حوار Codex، اكتب `@` وستظهر خيار "Yida". عند النقر، يدخل الذكاء الاصطناعي تلقائياً في وضع تطوير Yida:

```
@Yida ساعدني في إنشاء نظام إدارة مشاريع
```

### الطريقة 2: المحادثة المباشرة

لا حاجة لاستخدام @، يكفي ذكر كلمات مفتاحية متعلقة بـ "Yida" وسيستخدم الذكاء الاصطناعي إضافة OpenYida تلقائياً:

```
أنشئ نظام إدارة تدريب الموظفين على Yida، يشمل جدول الدورات ونموذج التسجيل وجدول درجات التقييم
```

---

## معلومات النموذج

يستخدم Codex النموذج المدمج من OpenAI، دون الحاجة لتهيئة يدوية. النموذج يدعم بشكل ممتاز كلاً من استدعاء الأدوات وتوليد الأكواد.

---

## ابدأ البناء

بعض أمثلة المحادثات:

```
ساعدني في إنشاء نظام CRM لإدارة علاقات العملاء:
- إدارة العملاء المحتملين: الاسم، الشركة، الهاتف، المصدر، حالة المتابعة
- ملف العميل: عميل محتمل مرتبط، القطاع، الإيرادات السنوية، مدير الحساب
- تتبع الفرص: عميل مرتبط، المبلغ، المرحلة، تاريخ الإغلاق المتوقع
```

```
أضف لوحة إحصائيات بيانات لتطبيقي، تعرض إجمالي قيمة الفرص ومعدل التحويل لهذا الشهر
```

```
ساعدني في تهيئة عملية موافقة: الإجازات التي تتجاوز 3 أيام تحتاج موافقة مدير القسم
```

---

## مثال محادثة فعلي

> **أنت**: @Yida أنشئ نظام تعويض نفقات السفر
>
> **الذكاء الاصطناعي**: حسناً، سأقوم بإنشاء نظام تعويض نفقات السفر.
>
> ✓ تم إنشاء تطبيق "إدارة تعويضات السفر"
> ✓ تم إنشاء نموذج "طلب السفر": مقدم الطلب، الوجهة، تاريخ المغادرة، تاريخ العودة، السبب
> ✓ تم إنشاء نموذج "تعويض النفقات": طلب سفر مرتبط، نوع النفقات (نموذج فرعي)، المبلغ الإجمالي، المرفقات
> ✓ تم تهيئة عملية الموافقة: مدير القسم → المالية
>
> رابط التطبيق: https://www.aliwork.com/APP_XXXXX/...
>
> هل تريد مني إنشاء لوحة إحصائيات التعويضات أيضاً؟

## قدرات Codex الحصرية

مقارنة ببيئات التطوير الأخرى، يتمتع OpenYida في Codex بعدة مزايا حصرية:

<CardGroup cols={2}>
  <Card title="إضافة أصلية" icon="puzzle-piece">
    مسجل في نظام إضافات Codex، وليس مجرد ملف مهارات. فهم الذكاء الاصطناعي لـ OpenYida أعمق.
  </Card>
  <Card title="MCP مدمج" icon="plug">
    خادم MCP يُهيأ تلقائياً. يتفاعل الذكاء الاصطناعي مع Yida عبر استدعاءات أدوات منظمة، وليس فقط تنفيذ أوامر.
  </Card>
  <Card title="مدخل قائمة @" icon="at">
    اختر "Yida" مباشرة من قائمة @، وادخل وضع تطوير التطبيقات بنقرة واحدة.
  </Card>
  <Card title="اختيار المؤسسة الأصلي" icon="building">
    في سيناريو المؤسسات المتعددة، اختر المؤسسة المستهدفة عبر عناصر تحكم واجهة Codex الأصلية، تجربة أكثر سلاسة.
  </Card>
</CardGroup>

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="لا أرى 'Yida' في قائمة @">
    تأكد من تثبيت OpenYida بشكل صحيح: `openyida --version`. إذا لم يظهر بعد التثبيت، أعد تشغيل Codex ليعيد مسح الإضافات. يمكنك أيضاً التحقق يدوياً من مجلد الإضافات:
    ```bash
    ls ~/.openyida/codex-plugin/plugins/openyida/.codex-plugin/plugin.json
    ```
  </Accordion>

  <Accordion title="لا يظهر اختيار المؤسسة عند تسجيل الدخول">
    إذا كنت تنتمي لمؤسسة Yida واحدة فقط، يتم اختيارها تلقائياً. عنصر التحكم يظهر فقط عند وجود عدة مؤسسات.
  </Accordion>

  <Accordion title="انتهت صلاحية تسجيل الدخول">
    قل للذكاء الاصطناعي "يبدو أن تسجيل الدخول إلى Yida انتهت صلاحيته"، وسيعيد تشغيل عملية تسجيل الدخول تلقائياً.
  </Accordion>

  <Accordion title="تحديث OpenYida">
    ```bash
    npm install -g openyida@latest
    ```
    بعد التحديث، يتم تحديث إضافة Codex تلقائياً أيضاً.
  </Accordion>
</AccordionGroup>
