Cursor هو محرر أكواد بالذكاء الاصطناعي مبني على VS Code، مع وضع Agent قوي مدمج. بعد تثبيت OpenYida، تحدث مباشرة في وضع Agent وسيقوم الذكاء الاصطناعي ببناء تطبيقات Yida تلقائياً.

---

## الإعداد لمرة واحدة

<Steps>
  <Step title="تحميل Cursor">
    قم بزيارة [cursor.com](https://cursor.com/) للتحميل والتثبيت. يدعم macOS / Windows / Linux.
  </Step>

  <Step title="تثبيت OpenYida">
    افتح الطرفية المدمجة في Cursor (`` Ctrl+` `` أو `` Cmd+` ``)، شغّل:

    ```bash
    npm install -g openyida
    ```

    يتم حقن حزمة المهارات تلقائياً، دون الحاجة لتهيئة إضافية.
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    افتح Composer (`Cmd+I`)، انتقل لوضع **Agent**، وقل:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```

    اتبع التعليمات لإكمال تسجيل الدخول عبر رمز QR أو المتصفح.
  </Step>
</Steps>

## اختيار النموذج

بدّل في محدد النماذج في Cursor. الموصى به:

| النموذج | السيناريو الموصى به |
|---------|---------------------|
| **Claude Sonnet 4** (موصى به) | قدرة قوية في استدعاء الأدوات، الخيار الأول للبناء اليومي |
| **Claude Opus 4** | أنظمة معقدة، نماذج متعددة مترابطة |
| GPT-4o | نماذج بسيطة، استجابة سريعة |

<Tip>
  يجب استخدام **وضع Agent** (وليس وضع Ask) ليتمكن الذكاء الاصطناعي من تنفيذ الأوامر. في Composer، انقر للتبديل إلى Agent.
</Tip>

## ابدأ البناء

في وضع Agent، صف متطلباتك مباشرة:

```
أنشئ نظام إدارة مشاريع على Yida:
- نموذج المشاريع: اسم المشروع، المسؤول، تاريخ البداية، تاريخ النهاية، الحالة
- نموذج المهام: مشروع مرتبط، اسم المهمة، الأولوية، المنفذ، الموعد النهائي
- أنشئ صفحة لوحة نظرة عامة على المشروع
```

```
ساعدني في إنشاء تطبيق حجز غرف الاجتماعات
```

```
أضف عملية موافقة على الاسترداد لتطبيق "إدارة الطلبات"
```

سينفذ الذكاء الاصطناعي جميع العمليات تلقائياً. ما عليك سوى رؤية النتائج وتقديم الملاحظات.

---

## مثال محادثة فعلي

> **أنت**: ساعدني في بناء نظام بسيط لجمع ملاحظات العملاء
>
> **الذكاء الاصطناعي**: سأساعدك في الإنشاء.
>
> ✓ تم إنشاء تطبيق "جمع ملاحظات العملاء"
> ✓ تم إنشاء نموذج: نوع الملاحظة (اقتراح/شكوى/استفسار)، اسم العميل، معلومات الاتصال، محتوى الملاحظة، الأولوية
> ✓ رابط التطبيق: https://www.aliwork.com/APP_XXXXX/...
>
> هل تريد مني إضافة لوحة إحصائيات الملاحظات؟

## وضع MCP (تعزيز اختياري)

إذا كنت تريد قدرات تصور تفاعلية (مثل بطاقات لوحة المعلومات، معاينة الرسوم البيانية)، يمكنك تهيئة MCP إضافياً. أنشئ `.cursor/mcp.json` في المجلد الجذري للمشروع:

```json
{
  "mcpServers": {
    "openyida": {
      "command": "npx",
      "args": ["-y", "@openyida/mcp-app", "--stdio"]
    }
  }
}
```

بعد التهيئة، أعد تشغيل Cursor. سيتمكن الذكاء الاصطناعي من عرض الرسوم البيانية ومعاينات النماذج من Yida مباشرة في المحادثة.

<Info>
  MCP هو ميزة تعزيز اختيارية. بدون تهيئة MCP، تعمل جميع القدرات الأساسية لـ OpenYida (إنشاء التطبيقات، النماذج، الصفحات، النشر، إلخ) بشكل طبيعي.
</Info>

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="الذكاء الاصطناعي لم يستدعِ OpenYida تلقائياً">
    تأكد أنك في **وضع Agent**. وضع Ask يجيب على الأسئلة فقط ولا ينفذ أوامر. كذلك، ذكر كلمة "Yida" في المحادثة يساعد الذكاء الاصطناعي على تحديد النية.
  </Accordion>

  <Accordion title="انتهت صلاحية تسجيل الدخول">
    قل للذكاء الاصطناعي "يبدو أن تسجيل الدخول إلى Yida انتهت صلاحيته، ساعدني في إعادة تسجيل الدخول".
  </Accordion>

  <Accordion title="أريد تحديث OpenYida">
    قل للذكاء الاصطناعي "ساعدني في تحديث openyida لأحدث إصدار" أو شغّل في الطرفية `npm install -g openyida@latest`.
  </Accordion>
</AccordionGroup>
