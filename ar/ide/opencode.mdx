OpenCode هو مساعد ذكاء اصطناعي مفتوح المصدر للطرفية، يدعم عدة واجهات خلفية للنماذج. بعد تثبيت OpenYida، يتم حقن حزمة المهارات تلقائياً. استخدم النموذج المفضل لديك لبناء تطبيقات Yida بالمحادثة.

---

## الإعداد لمرة واحدة

<Steps>
  <Step title="تثبيت OpenCode">
    ```bash
    # Homebrew (macOS)
    brew install opencode

    # أو Go install
    go install github.com/opencode-ai/opencode@latest
    ```

    لمزيد من التفاصيل راجع [opencode.ai](https://opencode.ai).
  </Step>

  <Step title="تهيئة مفتاح API للنموذج">
    يتطلب OpenCode أن تهيّئ النموذج بنفسك. يُوصى بـ Anthropic (سلسلة Claude):

    ```bash
    export ANTHROPIC_API_KEY="مفتاح API الخاص بك"
    ```

    يدعم أيضاً OpenAI و DeepSeek وواجهات أخرى متوافقة:

    ```bash
    # OpenAI
    export OPENAI_API_KEY="مفتاحك"

    # DeepSeek
    export OPENAI_API_KEY="مفتاحك"
    export OPENAI_BASE_URL="https://api.deepseek.com/v1"
    ```
  </Step>

  <Step title="تثبيت OpenYida">
    ```bash
    npm install -g openyida
    ```

    يتم حقن حزمة المهارات تلقائياً في OpenCode.
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    بعد تشغيل OpenCode، قل:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```
  </Step>
</Steps>

## النماذج الموصى بها

| النموذج | السيناريو الموصى به | ملاحظات |
|---------|---------------------|---------|
| **Claude Sonnet 4** (موصى به) | البناء اليومي | أقوى قدرة في استدعاء الأدوات |
| Claude Opus 4 | أنظمة معقدة | تفكير عميق |
| DeepSeek V3 | سيناريوهات صينية | أداء ممتاز مقابل التكلفة |
| GPT-4o | استخدام عام | متوازن |

<Tip>
  يجب أن يدعم النموذج استدعاء الأدوات (Tool Use / Function Calling) لتشغيل OpenYida. بعض النماذج مفتوحة المصدر الصغيرة قد لا تدعم ذلك. يُوصى بإعطاء الأولوية لـ Claude Sonnet 4.
</Tip>

## ابدأ البناء

تحدث مع الذكاء الاصطناعي لوصف متطلباتك:

```
أنشئ نظام شراء المواد على Yida:
- طلب الشراء: مقدم الطلب، اسم المادة، الكمية، الميزانية، الغرض
- عملية الموافقة: مدير القسم → الموافقة المالية
```

```
أنشئ تطبيق تسجيل للفعاليات، يشمل نموذج تسجيل ولوحة إحصائيات
```

```
اعرض جميع تطبيقاتي على Yida
```

## مثال محادثة فعلي

> **أنت**: ساعدني في إنشاء تطبيق جدول المناوبات
>
> **الذكاء الاصطناعي**: حسناً، سأقوم بإنشاء نظام جدول المناوبات.
>
> ✓ تم إنشاء تطبيق "جدول المناوبات"
> ✓ تم إنشاء نموذج "جدول المناوبات": التاريخ، الفترة، المناوب، ملاحظات
> ✓ تم إنشاء نموذج "طلب تبديل المناوبة": المناوب الأصلي، البديل، التاريخ، السبب
>
> هل تريد إضافة عملية موافقة لتبديل المناوبات؟
