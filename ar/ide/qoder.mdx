Qoder هو وكيل ذكاء اصطناعي لسطح المكتب. بعد تثبيت OpenYida، يتم حقن حزمة المهارات تلقائياً. صف متطلباتك مباشرة في المحادثة لبناء تطبيقات Yida.

---

## الإعداد لمرة واحدة

<Steps>
  <Step title="تحميل Qoder">
    قم بزيارة [qoder.com](https://qoder.com) لتحميل تطبيق سطح المكتب. يدعم macOS / Windows.
  </Step>

  <Step title="تثبيت OpenYida">
    ```bash
    npm install -g openyida
    ```

    يتم حقن حزمة المهارات تلقائياً في Qoder، دون الحاجة لتهيئة إضافية.
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    في محادثة Qoder، قل:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```

    اتبع التعليمات لإكمال تسجيل الدخول.
  </Step>
</Steps>

---

## اختيار النموذج

بدّل عبر محدد النماذج في واجهة محادثة Qoder:

| النموذج | السيناريو الموصى به |
|---------|---------------------|
| **Premium** | بناء تطبيقات معقدة، جداول متعددة مترابطة |
| **Standard** | الاستخدام اليومي، سريع |

لإنشاء نماذج بسيطة، Standard كافٍ. للأنظمة التجارية المعقدة، يُوصى بـ Premium.

---

## ابدأ البناء

صف متطلباتك مباشرة في المحادثة:

```
أنشئ نظام فحص المعدات على Yida:
- سجل المعدات: الرقم، الاسم، الموقع، الحالة، المسؤول
- سجلات الفحص: معدة مرتبطة، تاريخ الفحص، الفاحص، النتيجة، ملاحظات
```

```
ساعدني في بناء تطبيق بسيط لدليل الموظفين
```

```
أضف عملية موافقة لنظام التعويضات الخاص بي
```

ينفذ الذكاء الاصطناعي كل شيء تلقائياً. ما عليك سوى ذكر متطلباتك.

---

## مثال محادثة فعلي

> **أنت**: أنشئ تطبيق إدارة التوظيف
>
> **الذكاء الاصطناعي**: حسناً، سأساعدك في إنشاء نظام إدارة التوظيف.
>
> ✓ تم إنشاء تطبيق "إدارة التوظيف"
> ✓ تم إنشاء نموذج "معلومات الوظائف": اسم الوظيفة، القسم، المستوى، نطاق الراتب، الحالة
> ✓ تم إنشاء نموذج "المرشحين": الاسم، الوظيفة المتقدم لها، مرفق السيرة الذاتية، حالة المقابلة، التقييم
>
> هل تريد مني إضافة نموذج جدولة المقابلات؟

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="الذكاء الاصطناعي لم يتعرف على OpenYida">
    تأكد من نجاح التثبيت: `openyida --version`. مسار حزمة المهارات هو `~/.qoder/skills/yida-skills/`. إذا كان مفقوداً، شغّل `openyida copy -skills`.
  </Accordion>

  <Accordion title="انتهت صلاحية تسجيل الدخول">
    قل للذكاء الاصطناعي "انتهت صلاحية تسجيل الدخول إلى Yida، ساعدني في إعادة تسجيل الدخول".
  </Accordion>

  <Accordion title="تحديث OpenYida">
    قل للذكاء الاصطناعي "حدّث openyida" أو شغّل يدوياً `npm install -g openyida@latest`.
  </Accordion>
</AccordionGroup>
