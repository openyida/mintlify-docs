QoderWork هو تطبيق وكيل ذكاء اصطناعي مكتبي من Qoder، مصمم لتعزيز إنتاجية العمل اليومي. بعد تثبيت OpenYida، يتم حقن حزمة المهارات تلقائيًا، مما يتيح لك بناء تطبيقات Yida بمجرد وصف متطلباتك في المحادثة.

---

## الإعداد لمرة واحدة

<Steps>
  <Step title="تحميل QoderWork">
    قم بزيارة [qoder.com](https://qoder.com) لتحميل تطبيق QoderWork المكتبي، المتوفر لنظامي macOS / Windows.
  </Step>

  <Step title="تثبيت OpenYida">
    قم بتشغيل الأمر التالي في طرفية النظام:

    ```bash
    npm install -g openyida
    ```

    بعد التثبيت، يتم حقن حزمة المهارات تلقائيًا في QoderWork (المسار: `~/.qoderwork/skills/yida-skills/`) — لا حاجة لأي إعداد إضافي.
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    في محادثة QoderWork، قل:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```

    سيفتح الذكاء الاصطناعي متصفحًا لإكمال تسجيل الدخول. يتم تخزين بيانات الاعتماد مؤقتًا بعد أول تسجيل دخول، فلن تحتاج لتكراره.
  </Step>
</Steps>

<Tip>
  هذا كل شيء — اكتمل الإعداد. من الآن فصاعدًا، كل ما عليك فعله هو التحدث مع الذكاء الاصطناعي.
</Tip>

## اختيار النموذج

قم بتبديل النموذج عبر محدد النماذج في واجهة محادثة QoderWork:

| النموذج | حالة الاستخدام الموصى بها |
|---------|--------------------------|
| **Premium** (موصى به) | بناء تطبيقات معقدة، علاقات متعددة الجداول، قدرات استدعاء أدوات قوية |
| **Standard** | مهام يومية بسيطة، استجابة أسرع |

يُوصى باستخدام Premium لبناء تطبيقات Yida — استدعاء الأدوات أكثر استقرارًا.

## ابدأ البناء

صِف التطبيق المطلوب مباشرة في المحادثة:

```
أنشئ نظام فحص معدات على Yida:
- سجل المعدات: رقم، اسم، موقع، حالة، المسؤول
- سجلات الفحص: معدة مرتبطة، تاريخ الفحص، الفاحص، النتيجة، ملاحظات
```

```
ساعدني في إنشاء تطبيق دليل موظفين بسيط
```

```
أضف سير عمل موافقة إلى نظام تعويض المصاريف الخاص بي
```

الذكاء الاصطناعي ينفذ كل شيء تلقائيًا — فقط اذكر متطلباتك.

## مثال محادثة حقيقي

> **أنت**: أنشئ تطبيق إدارة توظيف
>
> **الذكاء الاصطناعي**: حسنًا، سأنشئ لك نظام إدارة توظيف.
>
> ✓ تم إنشاء تطبيق "إدارة التوظيف"
> ✓ تم إنشاء نموذج "معلومات الوظائف": اسم الوظيفة، القسم، المستوى، نطاق الراتب، الحالة
> ✓ تم إنشاء نموذج "المرشحون": الاسم، الوظيفة المتقدم لها، السيرة الذاتية المرفقة، حالة المقابلة، التقييم
>
> هل تريد مني إضافة نموذج سير عمل لجدولة المقابلات؟

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="الذكاء الاصطناعي لا يتعرف على OpenYida">
    تأكد من نجاح التثبيت: شغّل `openyida --version` في طرفية النظام. مسار حزمة المهارات هو `~/.qoderwork/skills/yida-skills/` — إذا كان مفقودًا، شغّل `openyida copy -skills`.
  </Accordion>

  <Accordion title="انتهاء صلاحية تسجيل الدخول">
    أخبر الذكاء الاصطناعي: "انتهت صلاحية تسجيل دخولي إلى Yida، ساعدني في تسجيل الدخول مرة أخرى."
  </Accordion>

  <Accordion title="تحديث OpenYida">
    أخبر الذكاء الاصطناعي: "ساعدني في تحديث openyida"، أو شغّل يدويًا `npm install -g openyida@latest`.
  </Accordion>
</AccordionGroup>
