يدعم Visual Studio Code استدعاء الأدوات من خلال وضع Agent في GitHub Copilot Chat. بعد تهيئة MCP، يمكنك بناء تطبيقات Yida بلغة طبيعية في VS Code.

---

## الإعداد لمرة واحدة

<Steps>
  <Step title="تثبيت GitHub Copilot Chat">
    في سوق إضافات VS Code، ابحث عن **GitHub Copilot** و **GitHub Copilot Chat** وقم بتثبيتهما. يتطلب اشتراك GitHub Copilot.
  </Step>

  <Step title="تثبيت OpenYida">
    افتح طرفية VS Code (`` Ctrl+` ``)، شغّل:

    ```bash
    npm install -g openyida
    ```
  </Step>

  <Step title="تهيئة MCP">
    أنشئ `.vscode/mcp.json` في المجلد الجذري للمشروع:

    ```json
    {
      "servers": {
        "openyida": {
          "command": "npx",
          "args": ["-y", "@openyida/mcp-app", "--stdio"]
        }
      }
    }
    ```

    أعد تحميل VS Code (`Cmd+Shift+P` → "Reload Window").
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    افتح Copilot Chat، انتقل لوضع Agent، وقل:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```
  </Step>
</Steps>

<Info>
  يحتاج Copilot Chat في VS Code إلى MCP لاستدعاء أدوات OpenYida. هذا مختلف عن Cursor و Claude Code (اللذين يتكاملان تلقائياً عبر حزمة المهارات).
</Info>

---

## اختيار النموذج

انقر على محدد النماذج في لوحة Copilot Chat للتبديل:

| النموذج | السيناريو الموصى به |
|---------|---------------------|
| **Claude Sonnet 4** (موصى به) | استدعاء الأدوات الأكثر استقراراً |
| GPT-4o | استجابة سريعة، مهام بسيطة |
| Claude Opus 4 | مهام معقدة (يتطلب Copilot Pro+) |

---

## ابدأ البناء

تحدث في وضع Agent في Copilot Chat:

```
ساعدني في إنشاء نظام إدارة المصروفات على Yida:
- نموذج طلب التعويض: مقدم الطلب، نوع المصروف، المبلغ، السبب، المرفقات
- عملية الموافقة: موافقة مدير القسم
```

```
أنشئ تطبيق محاضر الاجتماعات، لتسجيل موضوع الاجتماع والمشاركين والقرارات
```

```
تحقق من التطبيقات الموجودة لدي على Yida
```

سيكمل الذكاء الاصطناعي العمليات تلقائياً عبر أدوات MCP.

---

## مثال محادثة فعلي

> **أنت**: ساعدني في إنشاء نظام بسيط لاستعارة الكتب
>
> **الذكاء الاصطناعي**: سأقوم بالإنشاء عبر OpenYida.
>
> ✓ تم إنشاء تطبيق "إدارة استعارة الكتب"
> ✓ تم إنشاء نموذج "معلومات الكتب": عنوان الكتاب، المؤلف، ISBN، التصنيف، الكمية المتاحة
> ✓ تم إنشاء نموذج "سجلات الاستعارة": كتاب مرتبط، المستعير، تاريخ الاستعارة، تاريخ الإرجاع
>
> هل تريد مني إضافة صفحة بحث عن الكتب؟

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="لا يوجد وضع Agent في Copilot Chat">
    يتطلب VS Code 1.99+ وأحدث إصدار من إضافة Copilot Chat. قم بالتحديث وأعد تشغيل VS Code.
  </Accordion>

  <Accordion title="الذكاء الاصطناعي لا يستخدم أدوات OpenYida">
    تأكد من صحة تهيئة `.vscode/mcp.json` وأنه تم إعادة تحميل النافذة. اذكر "Yida" أو "openyida" صراحة في المحادثة لمساعدة Agent على تحديد النية.
  </Accordion>

  <Accordion title="فشل تشغيل خادم MCP">
    اختبر في الطرفية: `npx @openyida/mcp-app --stdio`. إذا ظهر خطأ، عادة ما يكون إصدار Node.js قديماً. قم بالترقية إلى 18+.
  </Accordion>
</AccordionGroup>
