Wukong هو مساعد البرمجة بالذكاء الاصطناعي المدمج في DingTalk. يتوافق OpenYida بعمق مع Wukong — بعد التثبيت، صف متطلباتك في المحادثة لبناء تطبيقات Yida.

---

## الإعداد لمرة واحدة

<Steps>
  <Step title="الدخول إلى مساحة عمل Wukong">
    افتح DingTalk → ادخل مساحة عمل Wukong. يأتي Wukong مع بيئة تشغيل Node.js مدمجة، لا حاجة لتثبيت منفصل.
  </Step>

  <Step title="تثبيت OpenYida">
    في طرفية Wukong، شغّل:

    ```bash
    npm install -g openyida
    ```

    <Warning>
      إذا ظهر خطأ في الصلاحيات، قم أولاً بتهيئة مسار Node.js المدمج في Wukong:
      ```bash
      export PATH="$HOME/.real/.bin/node/bin:$PATH"
      npm install -g openyida
      ```
    </Warning>
  </Step>

  <Step title="اطلب من الذكاء الاصطناعي تسجيل الدخول إلى Yida">
    قل مباشرة في محادثة Wukong:

    ```
    ساعدني في تسجيل الدخول إلى Yida
    ```

    يُوصى باستخدام طريقة مسح رمز QR — سيعرض الذكاء الاصطناعي رمز QR في مربع الحوار، امسحه بتطبيق DingTalk على هاتفك.
  </Step>
</Steps>

## معلومات النموذج

يستخدم Wukong نموذج الذكاء الاصطناعي الموحد المقدم من منصة DingTalk، دون الحاجة لتهيئة يدوية. النموذج محسّن بعمق للسيناريوهات الصينية والعمل المؤسسي. استخدمه مباشرة.

```
ساعدني في بناء تطبيق حجز غرف الاجتماعات

```

## ملاحظات خاصة بـ Wukong

<Info>
  مساحة عمل Wukong هي بيئة معزولة (sandbox)، هناك بعض النقاط الخاصة التي يجب معرفتها:

  - **مسار مساحة العمل**: يحتوي على UUID ديناميكي (`~/.real/users/{uuid}/workspace/`)، يتعرف عليه OpenYida تلقائياً
  - **تهيئة الملفات**: في المرة الأولى، قل للذكاء الاصطناعي "هيّئ مساحة عمل Yida"، وسيتعامل مع الأمر تلقائياً
  - **مهلة الأوامر**: إذا كانت عملية ما بطيئة، اطلب من الذكاء الاصطناعي التنفيذ خطوة بخطوة
</Info>

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="npm install يظهر خطأ صلاحيات">
    قم بتهيئة مسار Node.js المدمج في Wukong ثم أعد المحاولة:
    ```bash
    export PATH="$HOME/.real/.bin/node/bin:$PATH"
    npm install -g openyida
    ```
  </Accordion>

  <Accordion title="الذكاء الاصطناعي لا يتعرف على أوامر Yida">
    تأكد من نجاح التثبيت: شغّل `openyida --version` في طرفية Wukong. إذا كان الأمر موجوداً لكن الذكاء الاصطناعي لا يستجيب، اذكر كلمة "Yida" صراحة في المحادثة.
  </Accordion>

  <Accordion title="رمز QR لتسجيل الدخول لا يظهر">
    قل للذكاء الاصطناعي: "سجل الدخول إلى Yida بطريقة مسح رمز QR". سيستخدم الذكاء الاصطناعي وضع `--agent-qr` لعرض رمز QR في مربع الحوار.
  </Accordion>
</AccordionGroup>
