Custom display pages are React-style Yida pages compiled and published by OpenYida. They are the right fit for dashboards, portals, visual reports, calculators, and rich interactive pages.

## End-to-end flow

```bash
openyida create-page <appType> "Dashboard"
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
openyida publish project/pages/src/dashboard.oyd.jsx <appType> <formUuid>
```

`create-page` returns the page `formUuid`. Do not invent this value. Save it in your project cache or read it from command output.

## Runtime rules

Yida custom pages run inside a React 16 class component runtime. Generated page source must follow these rules:

- Use `export function renderJsx()`.
- Use `export function didMount()` and `export function didUnmount()` for lifecycle work.
- Define custom methods as `export function methodName() {}`.
- Wrap event handlers, for example `onClick={(e) => { this.handleClick(e); }}`.
- Use arrow callbacks for `.map()` and `.filter()`.
- Avoid React Hooks such as `useState` and `useEffect`.
- Avoid `import` and `require` in page source.
- Use inline style objects for page styling.
- For input fields, prefer uncontrolled inputs with `defaultValue`.

## Validate before publishing

```bash
openyida check-page project/pages/src/dashboard.oyd.jsx
openyida compile project/pages/src/dashboard.oyd.jsx
```

`check-page` catches common Yida runtime mistakes. `compile` produces compatible build output under `project/pages/build/` and `project/pages/dist/`.

## Hide Yida navigation

Use this for full-screen dashboards or presentation pages:

```bash
openyida update-form-config <appType> <formUuid> false "Dashboard"
```

To show navigation again:

```bash
openyida update-form-config <appType> <formUuid> true "Dashboard"
```

## When to use `build-page`

```bash
openyida build-page project/pages/src/dashboard.oyd.jsx --write
```

`build-page` converts source to Yida-compatible JSX without publishing. It is useful for review, CI, or debugging compile output.
