QoderWork is a desktop AI agent application from Qoder, designed for everyday work productivity. After installing OpenYida, the skill pack is automatically injected, allowing you to build Yida apps simply by describing your needs in a conversation.

---

## One-Time Setup

<Steps>
  <Step title="Download QoderWork">
    Visit [qoder.com](https://qoder.com) to download the QoderWork desktop app, available for macOS / Windows.
  </Step>

  <Step title="Install OpenYida">
    Run in your system terminal:

    ```bash
    npm install -g openyida
    ```

    Once installed, the skill pack is automatically injected into QoderWork (path: `~/.qoderwork/skills/yida-skills/`) — no additional configuration needed.
  </Step>

  <Step title="Tell AI to Log In to Yida">
    In the QoderWork conversation, say:

    ```
    Help me log in to Yida
    ```

    The AI will open a browser for you to complete the login. Credentials are cached after the first login, so you won't need to repeat this.
  </Step>
</Steps>

<Tip>
  That's it — setup is complete. From here, you just need to chat with the AI.
</Tip>

## Model Selection

Switch models using the model selector in the QoderWork conversation interface:

| Model | Recommended Use Case |
|-------|---------------------|
| **Premium** (Recommended) | Complex app building, multi-table relationships, strong tool-calling capabilities |
| **Standard** | Simple daily tasks, faster response |

Premium is recommended for building Yida apps — tool calling is more reliable.

## Start Building

Describe the app you want directly in the conversation:

```
Create an equipment inspection system on Yida:
- Equipment registry: ID, name, location, status, responsible person
- Inspection records: linked equipment, inspection date, inspector, result, notes
```

```
Help me build a simple employee directory app
```

```
Add an approval workflow to my expense reimbursement system
```

The AI handles everything automatically — just state your requirements.

## FAQ

<AccordionGroup>
  <Accordion title="AI doesn't recognize OpenYida">
    Confirm the installation succeeded: run `openyida --version` in your system terminal. The skill pack path is `~/.qoderwork/skills/yida-skills/` — if it's missing, run `openyida copy -skills`.
  </Accordion>

  <Accordion title="Login expired">
    Tell the AI: "My Yida login has expired, help me log in again."
  </Accordion>

  <Accordion title="Update OpenYida">
    Tell the AI: "Help me update openyida," or manually run `npm install -g openyida@latest`.
  </Accordion>
</AccordionGroup>
