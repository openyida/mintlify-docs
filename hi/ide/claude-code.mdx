Claude Code, Anthropic का टर्मिनल AI असिस्टेंट है। OpenYida इंस्टॉल करने के बाद, बस AI से बात करें और वह स्वचालित रूप से सभी कमांड कॉल करके एप्लिकेशन निर्माण पूरा करेगा।

---

## एक बार की तैयारी

पूरी प्रक्रिया में बस दो स्टेप हैं, उसके बाद सब कुछ बातचीत से होगा।

<Steps>
  <Step title="OpenYida इंस्टॉल करें">
    सुनिश्चित करें कि [Node.js ≥ 18](https://nodejs.org) मौजूद है, फिर टर्मिनल में चलाएं:

    ```bash
    npm install -g openyida
    ```

    इंस्टॉलेशन के बाद, OpenYida का स्किल पैकेज स्वचालित रूप से Claude Code में इंजेक्ट हो जाता है, कोई अतिरिक्त कॉन्फ़िगरेशन की ज़रूरत नहीं।
  </Step>

  <Step title="AI से Yida में लॉगिन करने को कहें">
    Claude Code शुरू करें, सीधे कहें:

    ```
    मुझे Yida में लॉगिन करने में मदद करो
    ```

    AI स्वचालित रूप से लॉगिन कमांड कॉल करेगा, ब्राउज़र खोलेगा या QR कोड दिखाएगा। एक बार लॉगिन करने के बाद क्रेडेंशियल कैश हो जाते हैं, दोबारा करने की ज़रूरत नहीं।
  </Step>
</Steps>

<Tip>
  बस इतना ही, तैयारी पूरी। अब आगे बस AI से बात करें।
</Tip>

## मॉडल चयन

Claude Code डिफ़ॉल्ट रूप से Claude सीरीज़ मॉडल का उपयोग करता है, `/model` कमांड से स्विच कर सकते हैं:

| मॉडल | अनुशंसित परिदृश्य |
|-------|-------------------|
| **Claude Sonnet 4** (डिफ़ॉल्ट) | रोज़ाना एप्लिकेशन निर्माण, तेज़ |
| **Claude Opus 4** | जटिल मल्टी-फॉर्म बिज़नेस सिस्टम |

दोनों OpenYida को बहुत अच्छी तरह ड्राइव करते हैं। रोज़ाना उपयोग के लिए Sonnet काफ़ी है।

## निर्माण शुरू करें

सीधे प्राकृतिक भाषा में अपना मनचाहा एप्लिकेशन बताएं, AI पूरा प्रोसेस स्वचालित रूप से संभालेगा:

```
मुझे Yida पर एक CRM सिस्टम बनाने में मदद करो, जिसमें:
- लीड फॉर्म: नाम, कंपनी, फ़ोन, स्रोत, स्थिति
- कस्टमर फॉर्म: कंपनी का नाम, इंडस्ट्री, कॉन्टैक्ट, अकाउंट मैनेजर
- ऑपर्च्युनिटी फॉर्म: लिंक्ड कस्टमर, राशि, स्टेज, अपेक्षित क्लोज़ डेट
```

```
एक IT एसेट मैनेजमेंट एप्लिकेशन बनाओ, जिसमें डिवाइस जानकारी दर्ज की जा सके और इश्यू-रिटर्न ट्रैक हो
```

```
इस पेज को पब्लिश करो, पब्लिक एक्सेस सेट करो
```

AI स्वचालित रूप से एप्लिकेशन बनाना, फॉर्म बनाना, पेज पब्लिश करना जैसे सभी स्टेप पूरे करेगा। आपको कोई कमांड याद रखने की ज़रूरत नहीं।

## वास्तविक बातचीत उदाहरण

नीचे एक सामान्य बातचीत प्रवाह है:

> **आप**: मुझे एक कर्मचारी छुट्टी प्रणाली बनाने में मदद करो
>
> **AI**: ठीक है, मैं बनाता हूं। पहले एनवायरनमेंट और लॉगिन स्टेटस चेक करता हूं...
>
> एनवायरनमेंट ठीक है, लॉगिन हो चुका है। अब एप्लिकेशन बनाना शुरू करता हूं...
>
> छुट्टी प्रणाली बन गई! इसमें शामिल है:
> - छुट्टी आवेदन फॉर्म (आवेदक, छुट्टी का प्रकार, शुरू/अंत तिथि, कारण)
> - एप्लिकेशन लिंक: https://www.aliwork.com/APP_XXXXX/...
>
> क्या मैं अप्रूवल प्रोसेस भी जोड़ूं?

बस अपनी ज़रूरत बताएं, AI एक्ज़ीक्यूशन का ध्यान रखेगा।

## एडवांस उपयोग

जब आप अधिक परिचित हो जाएं, AI को अधिक सटीक निर्देश दे सकते हैं:

```
"कस्टमर इन्फ़ॉर्मेशन" फॉर्म की फ़ील्ड लिस्ट दिखाओ, मैं फ़ील्ड कॉन्फ़िगरेशन कन्फ़र्म करना चाहता हूं
```

```
इस curl कमांड से मुझे Yida कनेक्टर बनाकर दो:
curl -H "Authorization: Bearer xxx" https://api.example.com/users
```

```
चेक करो कि एनवायरनमेंट में कोई समस्या तो नहीं है
```
