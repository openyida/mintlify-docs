Codex, OpenAI का AI प्रोग्रामिंग वातावरण है। OpenYida का Codex में **नेटिव प्लगइन स्तर का इंटीग्रेशन** है — इंस्टॉल करने के बाद यह स्वचालित रूप से Codex के लोकल प्लगइन के रूप में रजिस्टर हो जाता है, `@` मेन्यू में सीधे "Yida" एंट्री दिखाई देती है, साथ ही बिल्ट-इन MCP Server टूल कॉलिंग क्षमता प्रदान करता है। यह सभी समर्थित IDE में सबसे गहरा इंटीग्रेशन है।

---

## एक बार की तैयारी

<Steps>
  <Step title="OpenYida इंस्टॉल करें">
    सुनिश्चित करें कि [Node.js ≥ 18](https://nodejs.org) मौजूद है, फिर चलाएं:

    ```bash
    npm install -g openyida
    ```

    इंस्टॉलेशन के बाद स्वचालित रूप से:
    - OpenYida को Codex लोकल प्लगइन के रूप में रजिस्टर किया जाता है (`@` मेन्यू में दिखता है)
    - MCP Server कॉन्फ़िगर होता है (AI सीधे Yida टूल्स कॉल कर सकता है)
    - पूरा स्किल पैकेज इंजेक्ट होता है
  </Step>

  <Step title="AI से Yida में लॉगिन करने को कहें">
    Codex खोलें, सीधे कहें:

    ```
    मुझे Yida में लॉगिन करने में मदद करो
    ```

    AI लोकल ब्राउज़र खोलकर लॉगिन पूरा करेगा। अगर आप कई संगठनों से जुड़े हैं, तो Codex नेटिव सिलेक्शन कंट्रोल दिखाएगा।
  </Step>
</Steps>

<Tip>
  इंस्टॉल करते ही उपयोग के लिए तैयार। OpenYida, Codex में "फर्स्ट-क्लास सिटीज़न" है — आपको CLI के अस्तित्व के बारे में जानने की भी ज़रूरत नहीं।
</Tip>

## उपयोग का तरीका

### तरीका 1: @ मेन्यू (अनुशंसित)

Codex डायलॉग बॉक्स में `@` टाइप करें, आपको "Yida" विकल्प दिखेगा। क्लिक करने पर AI स्वचालित रूप से Yida डेवलपमेंट मोड में आ जाता है:

```
@Yida मुझे एक प्रोजेक्ट मैनेजमेंट सिस्टम बनाने में मदद करो
```

### तरीका 2: सीधी बातचीत

@ का उपयोग ज़रूरी नहीं है, बस "Yida" से संबंधित कीवर्ड का उल्लेख करें, AI स्वचालित रूप से OpenYida प्लगइन का उपयोग करेगा:

```
Yida पर एक कर्मचारी प्रशिक्षण प्रबंधन प्रणाली बनाओ, जिसमें कोर्स टेबल, रजिस्ट्रेशन फॉर्म और मूल्यांकन स्कोर टेबल शामिल हो
```

## मॉडल जानकारी

Codex, OpenAI के बिल्ट-इन मॉडल का उपयोग करता है, मैन्युअल कॉन्फ़िगरेशन की आवश्यकता नहीं है। मॉडल टूल कॉलिंग और कोड जेनरेशन दोनों को अच्छी तरह सपोर्ट करता है।

- लीड मैनेजमेंट: नाम, कंपनी, फ़ोन, स्रोत, फ़ॉलो-अप स्थिति
- कस्टमर प्रोफ़ाइल: लिंक्ड लीड, इंडस्ट्री, वार्षिक राजस्व, अकाउंट मैनेजर
- ऑपर्च्युनिटी ट्रैकिंग: लिंक्ड कस्टमर, राशि, स्टेज, अपेक्षित क्लोज़ डेट

```
मेरे एप्लिकेशन में एक डेटा स्टैटिस्टिक्स डैशबोर्ड जोड़ो, जो इस महीने की कुल ऑपर्च्युनिटी वैल्यू और कन्वर्ज़न रेट दिखाए

```
एक अप्रूवल प्रोसेस कॉन्फ़िगर करने में मदद करो: 3 दिन से ज़्यादा की छुट्टी पर डिपार्टमेंट मैनेजर की अप्रूवल चाहिए
