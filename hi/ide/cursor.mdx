Cursor, VS Code पर आधारित AI कोड एडिटर है, जिसमें शक्तिशाली Agent मोड बिल्ट-इन है। OpenYida इंस्टॉल करने के बाद, Agent मोड में सीधे बातचीत करें और AI आपके Yida एप्लिकेशन स्वचालित रूप से बनाएगा।

---

## एक बार की तैयारी

<Steps>
  <Step title="Cursor डाउनलोड करें">
    [cursor.com](https://cursor.com/) पर जाकर डाउनलोड और इंस्टॉल करें। macOS / Windows / Linux सपोर्ट करता है।
  </Step>

  <Step title="OpenYida इंस्टॉल करें">
    Cursor का बिल्ट-इन टर्मिनल खोलें (`` Ctrl+` `` या `` Cmd+` ``), चलाएं:

    ```bash
    npm install -g openyida
    ```

    स्किल पैकेज स्वचालित रूप से इंजेक्ट हो जाता है, अतिरिक्त कॉन्फ़िगरेशन की ज़रूरत नहीं।
  </Step>

  <Step title="AI से Yida में लॉगिन करने को कहें">
    Composer खोलें (`Cmd+I`), **Agent** मोड में स्विच करें, कहें:

    ```
    मुझे Yida में लॉगिन करने में मदद करो
    ```

    निर्देशों का पालन करके QR कोड या ब्राउज़र लॉगिन पूरा करें।
  </Step>
</Steps>

## मॉडल चयन

Cursor के मॉडल सिलेक्टर में स्विच करें। अनुशंसित:

| मॉडल | अनुशंसित परिदृश्य |
|-------|-------------------|
| **Claude Sonnet 4** (अनुशंसित) | मज़बूत टूल कॉलिंग क्षमता, रोज़ाना निर्माण के लिए सर्वश्रेष्ठ |
| **Claude Opus 4** | जटिल सिस्टम, मल्टी-फॉर्म रिलेशन |
| GPT-4o | सरल फॉर्म, तेज़ रिस्पॉन्स |

<Tip>
  AI को कमांड एक्ज़ीक्यूट करने के लिए **Agent मोड** (Ask मोड नहीं) का उपयोग ज़रूरी है। Composer में क्लिक करके Agent पर स्विच करें।
</Tip>

## निर्माण शुरू करें

Agent मोड में सीधे ज़रूरत बताएं:

```
Yida पर एक प्रोजेक्ट मैनेजमेंट सिस्टम बनाओ:
- प्रोजेक्ट फॉर्म: प्रोजेक्ट नाम, ज़िम्मेदार व्यक्ति, शुरू तिथि, अंत तिथि, स्टेटस
- टास्क फॉर्म: लिंक्ड प्रोजेक्ट, टास्क नाम, प्राथमिकता, एक्ज़ीक्यूटर, डेडलाइन
- एक प्रोजेक्ट ओवरव्यू डैशबोर्ड पेज बनाओ
```

```
मुझे एक मीटिंग रूम बुकिंग एप्लिकेशन बनाने में मदद करो
```

```
"ऑर्डर मैनेजमेंट" एप्लिकेशन में रिफ़ंड अप्रूवल प्रोसेस जोड़ो
```

AI स्वचालित रूप से सभी ऑपरेशन एक्ज़ीक्यूट करेगा। आपको बस रिज़ल्ट देखना है और फ़ीडबैक देना है।

>
> **AI**: मैं बनाता हूं।
>

> ✓ फॉर्म बनाया: फ़ीडबैक टाइप (सुझाव/शिकायत/पूछताछ), कस्टमर नाम, कॉन्टैक्ट, फ़ीडबैक कंटेंट, प्राथमिकता

## MCP मोड (वैकल्पिक एन्हांसमेंट)

अगर आप इंटरैक्टिव विज़ुअलाइज़ेशन क्षमता चाहते हैं (जैसे डैशबोर्ड कार्ड, चार्ट प्रीव्यू), तो अतिरिक्त MCP कॉन्फ़िगर कर सकते हैं। प्रोजेक्ट रूट डायरेक्टरी में `.cursor/mcp.json` बनाएं:

```json
{
  "mcpServers": {
    "openyida": {
      "command": "npx",
      "args": ["-y", "@openyida/mcp-app", "--stdio"]
    }
  }
}
```

कॉन्फ़िगर करने के बाद Cursor रीस्टार्ट करें। AI बातचीत में Yida के चार्ट और फॉर्म प्रीव्यू सीधे रेंडर कर सकेगा।

<Info>
  MCP एक वैकल्पिक एन्हांसमेंट फ़ीचर है। MCP कॉन्फ़िगर किए बिना भी, OpenYida की सभी कोर क्षमताएं (एप्लिकेशन बनाना, फॉर्म, पेज, पब्लिश आदि) सामान्य रूप से काम करती हैं।
</Info>
