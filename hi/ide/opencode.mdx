OpenCode एक ओपन सोर्स टर्मिनल AI असिस्टेंट है, जो कई मॉडल बैकएंड सपोर्ट करता है। OpenYida इंस्टॉल करने के बाद स्किल पैकेज स्वचालित रूप से इंजेक्ट हो जाता है। अपनी पसंद के मॉडल के साथ बातचीत से Yida एप्लिकेशन बनाएं।

---

## एक बार की तैयारी

<Steps>
  <Step title="OpenCode इंस्टॉल करें">
    ```bash
    # Homebrew (macOS)
    brew install opencode

    # या Go install
    go install github.com/opencode-ai/opencode@latest
    ```

    अधिक जानकारी [opencode.ai](https://opencode.ai) पर देखें।
  </Step>

  <Step title="मॉडल API Key कॉन्फ़िगर करें">
    OpenCode में आपको स्वयं मॉडल कॉन्फ़िगर करना होगा। Anthropic (Claude सीरीज़) अनुशंसित:

    ```bash
    export ANTHROPIC_API_KEY="आपकी API Key"
    ```

    OpenAI, DeepSeek और अन्य कम्पैटिबल इंटरफ़ेस भी सपोर्ट करता है:

    ```bash
    # OpenAI
    export OPENAI_API_KEY="आपकी Key"

    # DeepSeek
    export OPENAI_API_KEY="आपकी Key"
    export OPENAI_BASE_URL="https://api.deepseek.com/v1"
    ```
  </Step>

  <Step title="OpenYida इंस्टॉल करें">
    ```bash
    npm install -g openyida
    ```

    स्किल पैकेज स्वचालित रूप से OpenCode में इंजेक्ट हो जाता है।
  </Step>

  <Step title="AI से Yida में लॉगिन करने को कहें">
    OpenCode शुरू करने के बाद कहें:

    ```
    मुझे Yida में लॉगिन करने में मदद करो
    ```
  </Step>
</Steps>

## अनुशंसित मॉडल

| मॉडल | अनुशंसित परिदृश्य | विवरण |
|-------|-------------------|--------|
| **Claude Sonnet 4** (अनुशंसित) | रोज़ाना निर्माण | सबसे मज़बूत टूल कॉलिंग क्षमता |
| Claude Opus 4 | जटिल सिस्टम | गहन तर्क |
| DeepSeek V3 | चीनी परिदृश्य | अच्छा मूल्य-प्रदर्शन अनुपात |
| GPT-4o | सामान्य | संतुलित |

<Tip>
  OpenYida को ड्राइव करने के लिए मॉडल को टूल कॉलिंग (Tool Use / Function Calling) सपोर्ट करना ज़रूरी है। कुछ छोटे ओपन सोर्स मॉडल सपोर्ट नहीं करते। Claude Sonnet 4 को प्राथमिकता दें।
</Tip>

## निर्माण शुरू करें

AI से बातचीत करके ज़रूरत बताएं:

```
Yida पर एक मटीरियल प्रोक्योरमेंट सिस्टम बनाओ:
- प्रोक्योरमेंट रिक्वेस्ट: आवेदक, मटीरियल नाम, मात्रा, बजट, उपयोग
- अप्रूवल प्रोसेस: डिपार्टमेंट मैनेजर → फ़ाइनेंस अप्रूवल
```

```
एक इवेंट रजिस्ट्रेशन एप्लिकेशन बनाओ, जिसमें रजिस्ट्रेशन फॉर्म और स्टैटिस्टिक्स डैशबोर्ड हो
```

```
मेरे Yida पर सभी एप्लिकेशन दिखाओ
```

## वास्तविक बातचीत उदाहरण

> **आप**: मुझे एक ड्यूटी शेड्यूलिंग एप्लिकेशन बनाने में मदद करो
>
> **AI**: ठीक है, मैं ड्यूटी शेड्यूलिंग सिस्टम बनाता हूं।
>
> ✓ "ड्यूटी शेड्यूलिंग" एप्लिकेशन बनाया
> ✓ "शेड्यूल टेबल" फॉर्म बनाया: तारीख, शिफ़्ट, ड्यूटी पर्सन, टिप्पणी
> ✓ "शिफ़्ट चेंज रिक्वेस्ट" फॉर्म बनाया: ओरिजिनल ड्यूटी पर्सन, रिप्लेसमेंट, तारीख, कारण
>
> क्या शिफ़्ट चेंज अप्रूवल प्रोसेस जोड़ना है?
