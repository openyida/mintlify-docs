QoderWork, Qoder द्वारा विकसित एक डेस्कटॉप AI एजेंट एप्लिकेशन है, जो दैनिक कार्य उत्पादकता के लिए डिज़ाइन किया गया है। OpenYida इंस्टॉल करने के बाद, स्किल पैक स्वचालित रूप से जुड़ जाता है, जिससे आप बातचीत में अपनी आवश्यकताओं का वर्णन करके Yida ऐप बना सकते हैं।

---

## एक बार का सेटअप

<Steps>
  <Step title="QoderWork डाउनलोड करें">
    QoderWork डेस्कटॉप ऐप डाउनलोड करने के लिए [qoder.com](https://qoder.com) पर जाएं। macOS / Windows के लिए उपलब्ध है।
  </Step>

  <Step title="OpenYida इंस्टॉल करें">
    अपने सिस्टम टर्मिनल में चलाएं:

    ```bash
    npm install -g openyida
    ```

    इंस्टॉल होने के बाद, स्किल पैक स्वचालित रूप से QoderWork में जुड़ जाता है (पथ: `~/.qoderwork/skills/yida-skills/`) — कोई अतिरिक्त कॉन्फ़िगरेशन आवश्यक नहीं।
  </Step>

  <Step title="AI से Yida में लॉगिन करने को कहें">
    QoderWork की बातचीत में कहें:

    ```
    Yida में लॉगिन करने में मेरी मदद करो
    ```

    AI एक ब्राउज़र खोलेगा जिससे आप लॉगिन पूरा कर सकें। पहली बार लॉगिन के बाद क्रेडेंशियल कैश हो जाते हैं, इसलिए आपको दोबारा करने की ज़रूरत नहीं।
  </Step>
</Steps>

<Tip>
  बस इतना ही — सेटअप पूरा हो गया। अब आपको बस AI से बात करनी है।
</Tip>

## मॉडल चयन

QoderWork बातचीत इंटरफ़ेस में मॉडल सेलेक्टर के माध्यम से स्विच करें:

| मॉडल | अनुशंसित उपयोग |
|-------|----------------|
| **Premium** (अनुशंसित) | जटिल ऐप निर्माण, मल्टी-टेबल संबंध, मजबूत टूल-कॉलिंग क्षमता |
| **Standard** | दैनिक सरल कार्य, तेज़ प्रतिक्रिया |

Yida ऐप बनाने के लिए Premium की सिफारिश की जाती है — टूल कॉलिंग अधिक स्थिर है।

## निर्माण शुरू करें

बातचीत में सीधे अपना वांछित ऐप वर्णित करें:

```
Yida पर एक उपकरण निरीक्षण प्रणाली बनाओ:
- उपकरण रजिस्टर: क्रमांक, नाम, स्थान, स्थिति, जिम्मेदार व्यक्ति
- निरीक्षण रिकॉर्ड: लिंक किया गया उपकरण, निरीक्षण तिथि, निरीक्षक, परिणाम, टिप्पणियां
```

```
मेरे लिए एक सरल कर्मचारी डायरेक्टरी ऐप बनाओ
```

```
मेरे खर्च प्रतिपूर्ति सिस्टम में एक अनुमोदन वर्कफ़्लो जोड़ो
```

AI सब कुछ स्वचालित रूप से करता है — बस अपनी आवश्यकताएं बताएं।

## वास्तविक बातचीत उदाहरण

> **आप**: एक भर्ती प्रबंधन ऐप बनाओ
>
> **AI**: ठीक है, मैं आपके लिए एक भर्ती प्रबंधन प्रणाली बनाता हूं।
>
> ✓ ऐप "भर्ती प्रबंधन" बनाया गया
> ✓ "पद जानकारी" फॉर्म बनाया गया: पद का नाम, विभाग, स्तर, वेतन सीमा, स्थिति
> ✓ "उम्मीदवार" फॉर्म बनाया गया: नाम, आवेदित पद, रिज़्यूमे अटैचमेंट, साक्षात्कार स्थिति, मूल्यांकन
>
> क्या आप चाहते हैं कि मैं साक्षात्कार शेड्यूलिंग के लिए एक वर्कफ़्लो फॉर्म जोड़ूं?
