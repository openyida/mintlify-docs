Visual Studio Code, GitHub Copilot Chat के Agent मोड के माध्यम से टूल कॉलिंग सपोर्ट करता है। MCP कॉन्फ़िगर करने के बाद, आप VS Code में प्राकृतिक भाषा से Yida एप्लिकेशन बना सकते हैं।

---

## एक बार की तैयारी

<Steps>
  <Step title="GitHub Copilot Chat इंस्टॉल करें">
    VS Code एक्सटेंशन मार्केटप्लेस में **GitHub Copilot** और **GitHub Copilot Chat** खोजें और इंस्टॉल करें। GitHub Copilot सब्सक्रिप्शन ज़रूरी है।
  </Step>

  <Step title="OpenYida इंस्टॉल करें">
    VS Code टर्मिनल खोलें (`` Ctrl+` ``), चलाएं:

    ```bash
    npm install -g openyida
    ```
  </Step>

  <Step title="MCP कॉन्फ़िगर करें">
    प्रोजेक्ट रूट डायरेक्टरी में `.vscode/mcp.json` बनाएं:

    ```json
    {
      "servers": {
        "openyida": {
          "command": "npx",
          "args": ["-y", "@openyida/mcp-app", "--stdio"]
        }
      }
    }
    ```

    VS Code रीलोड करें (`Cmd+Shift+P` → "Reload Window")।
  </Step>

  <Step title="AI से Yida में लॉगिन करने को कहें">
    Copilot Chat खोलें, Agent मोड में स्विच करें, कहें:

    ```
    मुझे Yida में लॉगिन करने में मदद करो
    ```
  </Step>
</Steps>

<Info>
  VS Code के Copilot Chat को OpenYida टूल्स कॉल करने के लिए MCP की ज़रूरत है। यह Cursor और Claude Code से अलग है (वे स्किल पैकेज के ज़रिए स्वचालित रूप से इंटीग्रेट होते हैं)।
</Info>

## मॉडल चयन

Copilot Chat पैनल में मॉडल सिलेक्टर पर क्लिक करके स्विच करें:

| मॉडल | अनुशंसित परिदृश्य |
|-------|-------------------|
| **Claude Sonnet 4** (अनुशंसित) | सबसे स्थिर टूल कॉलिंग |
| GPT-4o | तेज़ रिस्पॉन्स, सरल कार्य |
| Claude Opus 4 | जटिल कार्य (Copilot Pro+ ज़रूरी) |

---

## निर्माण शुरू करें

Copilot Chat के Agent मोड में बातचीत करें:

```
मुझे Yida पर रीइम्बर्समेंट मैनेजमेंट सिस्टम बनाने में मदद करो:
- रीइम्बर्समेंट रिक्वेस्ट फॉर्म: आवेदक, खर्च प्रकार, राशि, कारण, अटैचमेंट
- अप्रूवल प्रोसेस: डिपार्टमेंट मैनेजर अप्रूवल
```

```
एक मीटिंग मिनट्स एप्लिकेशन बनाओ, जिसमें मीटिंग का विषय, प्रतिभागी और निर्णय रिकॉर्ड हो
```

```
देखो मेरे Yida पर कौन-कौन से एप्लिकेशन हैं
```

AI, MCP टूल्स के माध्यम से स्वचालित रूप से ऑपरेशन पूरा करेगा।

## वास्तविक बातचीत उदाहरण

> **आप**: मुझे एक सरल पुस्तक उधार प्रणाली बनाने में मदद करो
>
> **AI**: मैं OpenYida के माध्यम से बनाता हूं।
>
> ✓ "पुस्तक उधार प्रबंधन" एप्लिकेशन बनाया
> ✓ "पुस्तक जानकारी" फॉर्म बनाया: पुस्तक का नाम, लेखक, ISBN, श्रेणी, स्टॉक संख्या
> ✓ "उधार रिकॉर्ड" फॉर्म बनाया: लिंक्ड पुस्तक, उधार लेने वाला, उधार तिथि, वापसी तिथि
>
> क्या मैं पुस्तक खोज का डिस्प्ले पेज जोड़ूं?
