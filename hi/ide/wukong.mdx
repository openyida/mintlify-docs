Wukong, DingTalk का बिल्ट-इन AI प्रोग्रामिंग असिस्टेंट है। OpenYida, Wukong के साथ गहराई से अनुकूलित है — इंस्टॉल करने के बाद बातचीत में ज़रूरत बताएं और Yida एप्लिकेशन बनाएं।

---

## एक बार की तैयारी

<Steps>
  <Step title="Wukong वर्कस्पेस में जाएं">
    DingTalk खोलें → Wukong वर्कस्पेस में जाएं। Wukong में Node.js रनटाइम पहले से शामिल है, अलग से इंस्टॉल करने की ज़रूरत नहीं।
  </Step>

  <Step title="OpenYida इंस्टॉल करें">
    Wukong टर्मिनल में चलाएं:

    ```bash
    npm install -g openyida
    ```

    <Warning>
      अगर परमिशन एरर दिखे, पहले Wukong के बिल्ट-इन Node.js पाथ कॉन्फ़िगर करें:
      ```bash
      export PATH="$HOME/.real/.bin/node/bin:$PATH"
      npm install -g openyida
      ```
    </Warning>
  </Step>

  <Step title="AI से Yida में लॉगिन करने को कहें">
    Wukong की बातचीत में सीधे कहें:

    ```
    मुझे Yida में लॉगिन करने में मदद करो
    ```

    QR कोड स्कैन विधि अनुशंसित है — AI डायलॉग बॉक्स में QR कोड दिखाएगा, मोबाइल DingTalk से स्कैन करें।
  </Step>
</Steps>

---

## मॉडल जानकारी

Wukong, DingTalk प्लेटफ़ॉर्म द्वारा प्रदान किए गए एकीकृत AI मॉडल का उपयोग करता है, मैन्युअल कॉन्फ़िगरेशन की ज़रूरत नहीं। मॉडल चीनी परिदृश्यों और एंटरप्राइज़ ऑफ़िस के लिए गहराई से ऑप्टिमाइज़ है। सीधे उपयोग करें।

---

## निर्माण शुरू करें

Wukong की बातचीत में सीधे ज़रूरत बताएं:

```
Yida पर एक ट्रैवल रीइम्बर्समेंट सिस्टम बनाओ:
- ट्रैवल रिक्वेस्ट: आवेदक, उद्देश्य, प्रस्थान स्थान, गंतव्य, तारीख
- खर्च रीइम्बर्समेंट: लिंक्ड ट्रैवल रिक्वेस्ट, खर्च विवरण, राशि, रसीद
- अप्रूवल प्रोसेस
```

```
मुझे एक मीटिंग रूम बुकिंग एप्लिकेशन बनाने में मदद करो
```

```
अभी बनाए पेज को पब्लिक लिंक के रूप में पब्लिश करो
```

>
> ✓ "वीकली रिपोर्ट मैनेजमेंट" एप्लिकेशन बनाया

> ✓ एप्लिकेशन लिंक: https://www.aliwork.com/APP_XXXXX/...
>
> क्या मैं टीम वीकली रिपोर्ट समरी डैशबोर्ड जोड़ूं?

## Wukong विशेष नोट

<Info>
  Wukong वर्कस्पेस एक सैंडबॉक्स वातावरण है, कुछ विशेष बातें जानने योग्य हैं:

  - **वर्कस्पेस पाथ**: डायनामिक UUID शामिल है (`~/.real/users/{uuid}/workspace/`), OpenYida स्वचालित रूप से पहचानता है
  - **फ़ाइल इनिशियलाइज़ेशन**: पहली बार उपयोग करते समय AI से कहें "Yida वर्कस्पेस इनिशियलाइज़ करो", AI स्वचालित रूप से संभालेगा
  - **कमांड टाइमआउट**: अगर कोई ऑपरेशन धीमा हो, AI से स्टेप बाई स्टेप एक्ज़ीक्यूट करने को कहें
</Info>

## अक्सर पूछे जाने वाले प्रश्न

<AccordionGroup>
  <Accordion title="npm install में परमिशन एरर दिख रहा">
    Wukong के बिल्ट-इन Node.js पाथ कॉन्फ़िगर करके फिर से प्रयास करें:
    ```bash
    export PATH="$HOME/.real/.bin/node/bin:$PATH"

    ```
  </Accordion>

  <Accordion title="AI, Yida संबंधित कमांड नहीं पहचान रहा">

  </Accordion>

  <Accordion title="लॉगिन QR कोड नहीं दिख रहा">
    AI से कहें: "QR कोड स्कैन से Yida में लॉगिन करो"। AI, `--agent-qr` मोड से डायलॉग बॉक्स में QR कोड दिखाएगा।
  </Accordion>
</AccordionGroup>
