Claude Code は Anthropic が提供するターミナル AI アシスタントです。OpenYida をインストールすれば、AI と対話するだけで、すべてのコマンドを自動的に呼び出してアプリ構築を完了します。

---

## 初期セットアップ

プロセス全体はたった 2 ステップです。その後は純粋に対話だけで操作できます。

<Steps>
  <Step title="OpenYida をインストール">
    [Node.js >= 18](https://nodejs.org) がインストール済みであることを確認し、ターミナルで実行します：

    ```bash
    npm install -g openyida
    ```

    インストール完了後、OpenYida のスキルパックが自動的に Claude Code に注入されます。他の設定は不要です。
  </Step>

  <Step title="AI に Yida へのログインを依頼">
    Claude Code を起動し、直接話しかけます：

    ```
    Yidaにログインして
    ```

    AI がログインコマンドを自動的に呼び出し、ブラウザを開くか QR コードを表示してスキャンします。一度ログインすれば認証情報がキャッシュされ、以降は繰り返す必要はありません。
  </Step>
</Steps>

<Tip>
  これだけです。準備完了です。あとは AI と対話するだけです。
</Tip>

---

## モデル選択

Claude Code はデフォルトで Claude シリーズモデルを使用します。`/model` コマンドで切り替えできます：

| モデル | 推奨シーン |
|------|----------|
| **Claude Sonnet 4**（デフォルト） | 日常的なアプリ構築、高速 |
| **Claude Opus 4** | 複雑なマルチフォーム業務システム |

どちらも OpenYida を十分に駆動できます。日常使用には Sonnet で十分です。

## 構築を始める

自然言語で欲しいアプリを記述するだけで、AI が全工程を自動処理します：

```
Yidaで CRM システムを作成して：
- リードフォーム：氏名、会社、電話番号、ソース、ステータス
- 顧客フォーム：会社名、業界、連絡先、担当者
- 商談フォーム：顧客連携、金額、ステージ、成約予定日
```

```
IT資産管理アプリを作成して、機器情報の登録と貸出・返却の追跡ができるようにして
```

```
このページを公開して、パブリックアクセスに設定して
```

AI がアプリ作成、フォーム作成、ページ公開などすべてのステップを自動的に完了します。コマンドを覚える必要はありません。

## 実際の対話例

以下は典型的な対話フローです：

> **あなた**：社員休暇申請システムを作成して
>
> **AI**：わかりました。作成します。まず環境とログイン状態を確認します...
>
> 環境は正常、ログイン済みです。アプリの作成を開始します...
>
> 休暇申請システムの作成が完了しました！内容：
> - 休暇申請フォーム（申請者、休暇種別、開始日/終了日、理由）
> - アプリリンク：https://www.aliwork.com/APP_XXXXX/...
>
> 承認フローも追加しますか？

全工程で必要なのは要件を伝えることだけ。AI が実行を担当します。

## よくある質問

<AccordionGroup>
  <Accordion title="AI が openyida コマンドを見つけられないと言う">
    ターミナルでインストールを確認してください：`openyida --version`。インストール済みなのに Claude Code が見つけられない場合は、Claude Code を終了して再起動してください。
  </Accordion>

  <Accordion title="ログインが切れた場合">
    AI に直接「Yidaに再ログインして」と伝えてください。自動的に処理されます。
  </Accordion>

  <Accordion title="AI が OpenYida スキルを使用しない">
    対話で「Yida」キーワードを言及すればトリガーされます。例えば「Yidaでフォームを作成して」。
  </Accordion>

  <Accordion title="最新バージョンにアップデートしたい">
    AI に「openyidaをアップデートして」と伝えるか、手動で `npm install -g openyida@latest` を実行してください。
  </Accordion>
</AccordionGroup>
