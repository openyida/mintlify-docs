Codex は OpenAI が提供する AI プログラミング環境です。OpenYida は Codex に**ネイティブプラグインレベルの統合**を行っています。インストール後、自動的に Codex ローカルプラグインとして登録され、`@` メニューに「Yida」エントリが直接表示されます。同時に内蔵の MCP Server がツール呼び出し機能を提供します。これはサポートされているすべての IDE の中で最も深い統合です。

---

## 初期セットアップ

<Steps>
  <Step title="OpenYida をインストール">
    [Node.js >= 18](https://nodejs.org) がインストール済みであることを確認し、以下を実行します：

    ```bash
    npm install -g openyida
    ```

    インストール完了後、自動的に以下が行われます：
    - OpenYida を Codex ローカルプラグインとして登録（`@` メニューに表示）
    - MCP Server を設定（AI が Yida ツールを直接呼び出し可能に）
    - 完全なスキルパックを注入
  </Step>

  <Step title="AI に Yida へのログインを依頼">
    Codex を開き、直接話しかけます：

    ```
    Yidaにログインして
    ```

    AI がローカルブラウザを開いてログインを完了します。複数の組織に所属している場合、Codex がネイティブの選択コントロールを表示して選択できます。
  </Step>
</Steps>

<Tip>
  インストールすればすぐに使えます。OpenYida は Codex では「プラグインレベルのファーストクラス」です。CLI の存在を知る必要すらありません。
</Tip>

## 使い方

### 方法 1：@ メニュー（推奨）

Codex のダイアログで `@` を入力すると、「Yida」オプションが表示されます。クリックすると AI が自動的に Yida 開発モードに入ります：

```
@Yida プロジェクト管理システムを作成して
```

### 方法 2：直接対話

@ を使わなくても、「Yida」関連のキーワードを言及するだけで、AI が自動的に OpenYida プラグインを使用します：

```
Yidaで社員研修管理システムを構築して。コース表、申込フォーム、評価成績表を含めて
```

---

## モデルについて

Codex は OpenAI 内蔵モデルを使用するため、手動設定は不要です。モデルはツール呼び出しとコード生成の両方に優れたサポートを提供します。

---

## 構築を始める

対話の例をいくつか紹介します：

```
CRM顧客管理システムを作成して：
- リード管理：氏名、会社、電話番号、ソース、フォローアップ状態
- 顧客ファイル：リード連携、業界、年間売上、担当者
- 商談追跡：顧客連携、金額、ステージ、成約予定日
```

```
アプリにデータ統計ダッシュボードを追加して、今月の商談総額と成約率を表示して
```

```
承認フローを設定して：3日を超える休暇は部門マネージャーの承認が必要
```

## 実際の対話例

> **あなた**：@Yida 出張精算システムを作って
>
> **AI**：わかりました。出張精算システムを作成します。
>
> ✓ アプリ「出張精算管理」を作成しました
> ✓ 「出張申請」フォームを作成しました：申請者、目的地、出発日、帰着日、理由
> ✓ 「経費精算」フォームを作成しました：出張申請連携、費用種別（サブフォーム）、合計金額、添付ファイル
> ✓ 承認フローを設定しました：部門マネージャー → 経理
>
> アプリリンク：https://www.yidaapps.com/APP_XXXXX/...
>
> 精算統計ダッシュボードも作成しますか？

## Codex 独自の機能

他の IDE と比較して、OpenYida は Codex でいくつかの独自の利点があります：

<CardGroup cols={2}>
  <Card title="ネイティブプラグイン" icon="puzzle-piece">
    Codex プラグインシステムに登録されており、単なるスキルファイルではありません。AI の OpenYida に対する理解がより深くなります。
  </Card>
  <Card title="MCP 内蔵" icon="plug">
    MCP Server が自動設定され、AI は構造化ツール呼び出しで Yida と対話できます。コマンド実行だけではありません。
  </Card>
  <Card title="@ メニューエントリ" icon="at">
    @ メニューで直接「Yida」を選択し、ワンクリックでアプリ開発モードに入ります。
  </Card>
  <Card title="ネイティブ組織選択" icon="building">
    複数組織のシナリオでは、Codex ネイティブ UI コントロールで対象組織を選択でき、よりスムーズな体験です。
  </Card>
</CardGroup>

## よくある質問

<AccordionGroup>
  <Accordion title="@ メニューに「Yida」が表示されない">
    OpenYida が正しくインストールされていることを確認してください：`openyida --version`。インストール後も表示されない場合は、Codex を再起動してプラグインを再スキャンさせてください。手動でプラグインディレクトリを確認することもできます：
    ```bash
    ls ~/.openyida/codex-plugin/plugins/openyida/.codex-plugin/plugin.json
    ```
  </Accordion>

  <Accordion title="ログイン時に組織選択が表示されない">
    所属する Yida 組織が 1 つだけの場合は自動的に選択されます。複数組織の場合のみ選択コントロールが表示されます。
  </Accordion>

  <Accordion title="ログインの有効期限切れ">
    AI に「Yidaのログインが切れたみたい」と伝えてください。自動的に再ログインフローをトリガーします。
  </Accordion>

  <Accordion title="OpenYida のアップデート">
    ```bash
    npm install -g openyida@latest
    ```
    アップデート後、Codex プラグインも自動的に更新されます。
  </Accordion>
</AccordionGroup>
