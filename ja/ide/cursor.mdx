Cursor は VS Code ベースの AI コードエディタで、強力な Agent モードを内蔵しています。OpenYida をインストールすれば、Agent モードで直接対話するだけで、AI が Yida アプリを自動構築します。

---

## 初期セットアップ

<Steps>
  <Step title="Cursor をダウンロード">
    [cursor.com](https://cursor.com/) にアクセスしてダウンロード・インストールします。macOS / Windows / Linux をサポートしています。
  </Step>

  <Step title="OpenYida をインストール">
    Cursor の内蔵ターミナル（`` Ctrl+` `` または `` Cmd+` ``）を開き、実行します：

    ```bash
    npm install -g openyida
    ```

    スキルパックが自動的に注入され、追加の設定は不要です。
  </Step>

  <Step title="AI に Yida へのログインを依頼">
    Composer（`Cmd+I`）を開き、**Agent** モードに切り替えて、次のように言います：

    ```
    Yidaにログインして
    ```

    指示に従って QR コードスキャンまたはブラウザログインを完了してください。
  </Step>
</Steps>

## モデル選択

Cursor のモデルセレクターで切り替えます。推奨：

| モデル | 推奨シーン |
|------|----------|
| **Claude Sonnet 4**（推奨） | ツール呼び出し能力が強く、日常構築に最適 |
| **Claude Opus 4** | 複雑なシステム、マルチフォーム連携 |
| GPT-4o | シンプルなフォーム、高速レスポンス |

<Tip>
  AI にコマンドを実行させるには、必ず **Agent モード**（Ask モードではなく）を使用してください。Composer でモードを Agent に切り替えてください。
</Tip>

---

## 構築を始める

Agent モードで要件を直接記述します：

```
Yidaでプロジェクト管理システムを作成して：
- プロジェクトフォーム：プロジェクト名、責任者、開始日、終了日、ステータス
- タスクフォーム：プロジェクト連携、タスク名、優先度、担当者、期限
- プロジェクト概要のダッシュボードページを作成して
```

```
会議室予約アプリを作成して
```

```
「注文管理」アプリに返金承認フローを追加して
```

AI がすべての操作を自動実行します。結果を確認してフィードバックを返すだけです。

## MCP モード（オプション拡張）

インタラクティブな可視化機能（ダッシュボードカード、チャートプレビューなど）が必要な場合は、MCP を追加設定できます。プロジェクトルートに `.cursor/mcp.json` を作成します：

```json
{
  "mcpServers": {
    "openyida": {
      "command": "npx",
      "args": ["-y", "@openyida/mcp-app", "--stdio"]
    }
  }
}
```

設定後に Cursor を再起動すると、AI の対話中に Yida のチャートやフォームプレビューを直接レンダリングできるようになります。

<Info>
  MCP はオプションの拡張機能です。MCP を設定しなくても、OpenYida のすべてのコア機能（アプリ作成、フォーム、ページ、公開など）は正常に使用できます。
</Info>

## よくある質問

<AccordionGroup>
  <Accordion title="AI が OpenYida を自動的に呼び出さない">
    **Agent モード**であることを確認してください。Ask モードは質問に回答するだけで、コマンドを実行できません。また、対話で「Yida」キーワードを言及すると AI の意図認識に役立ちます。
  </Accordion>

  <Accordion title="ログインが切れた">
    AI に「Yidaのログインが切れたみたい、再ログインして」と伝えてください。
  </Accordion>

  <Accordion title="OpenYida をアップデートしたい">
    AI に「openyidaを最新版にアップデートして」と伝えるか、ターミナルで `npm install -g openyida@latest` を実行してください。
  </Accordion>
</AccordionGroup>
