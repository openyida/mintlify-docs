Qoder はデスクトップ向け AI エージェントです。OpenYida をインストールするとスキルパックが自動注入され、対話で要件を記述するだけで Yida アプリを構築できます。

---

## 初期セットアップ

<Steps>
  <Step title="Qoder をダウンロード">
    [qoder.com](https://qoder.com) にアクセスしてデスクトップアプリをダウンロードします。macOS / Windows をサポートしています。
  </Step>

  <Step title="OpenYida をインストール">
    ```bash
    npm install -g openyida
    ```

    スキルパックが自動的に Qoder に注入されます。追加の設定は不要です。
  </Step>

  <Step title="AI に Yida へのログインを依頼">
    Qoder の対話画面で次のように言います：

    ```
    Yidaにログインして
    ```

    指示に従ってログインを完了してください。
  </Step>
</Steps>

---

## モデル選択

Qoder の対話画面でモデルセレクターを使って切り替えます：

| モデル | 推奨シーン |
|------|----------|
| **Premium** | 複雑なアプリ構築、マルチテーブル連携 |
| **Standard** | 日常使用、高速 |

シンプルなフォーム作成には Standard で十分です。複雑な業務システムには Premium をお勧めします。

---

## 構築を始める

対話で直接要件を記述します：

```
Yidaで設備点検システムを作成して：
- 設備台帳：番号、名称、設置場所、ステータス、責任者
- 点検記録：設備連携、点検日、点検者、結果、備考
```

```
シンプルな社員連絡帳アプリを作って
```

```
経費精算システムに承認フローを追加して
```

AI が全工程を自動実行します。要件を伝えるだけで OK です。

## よくある質問

<AccordionGroup>
  <Accordion title="AI が OpenYida を認識しない">
    インストールを確認してください：`openyida --version`。スキルパックのパスは `~/.qoder/skills/yida-skills/` です。見つからない場合は `openyida copy -skills` を実行してください。
  </Accordion>

  <Accordion title="ログインの有効期限切れ">
    AI に「Yidaのログインが切れたので再ログインして」と伝えてください。
  </Accordion>

  <Accordion title="OpenYida のアップデート">
    AI に「openyidaをアップデートして」と伝えるか、手動で `npm install -g openyida@latest` を実行してください。
  </Accordion>
</AccordionGroup>
