Claude Code는 Anthropic이 제공하는 터미널 AI 어시스턴트입니다. OpenYida를 설치하면 AI와 대화하기만 하면 모든 명령을 자동으로 호출하여 앱 구축을 완료합니다.

---

## 초기 설정

전체 과정은 단 2단계입니다. 이후에는 순수하게 대화만으로 조작할 수 있습니다.

<Steps>
  <Step title="OpenYida 설치">
    [Node.js >= 18](https://nodejs.org)이 설치되어 있는지 확인한 후 터미널에서 실행합니다:

    ```bash
    npm install -g openyida
    ```

    설치 완료 후, OpenYida의 스킬팩이 자동으로 Claude Code에 주입됩니다. 다른 설정은 필요 없습니다.
  </Step>

  <Step title="AI에게 Yida 로그인 요청">
    Claude Code를 시작하고 직접 말합니다:

    ```
    Yida에 로그인해 줘
    ```

    AI가 로그인 명령을 자동으로 호출하여 브라우저를 열거나 QR 코드를 표시합니다. 한 번 로그인하면 인증 정보가 캐시되어 이후 반복할 필요가 없습니다.
  </Step>
</Steps>

<Tip>
  이게 전부입니다. 준비 완료입니다. 이제부터는 AI와 대화하기만 하면 됩니다.
</Tip>

---

## 모델 선택

Claude Code는 기본적으로 Claude 시리즈 모델을 사용합니다. `/model` 명령으로 전환할 수 있습니다:

| 모델 | 권장 시나리오 |
|------|----------|
| **Claude Sonnet 4** (기본) | 일상적인 앱 구축, 빠른 속도 |
| **Claude Opus 4** | 복잡한 다중 양식 업무 시스템 |

둘 다 OpenYida를 잘 구동할 수 있습니다. 일상적인 사용에는 Sonnet으로 충분합니다.

---

## 구축 시작

자연어로 원하는 앱을 설명하면 AI가 전 과정을 자동 처리합니다:

```
Yida에서 CRM 시스템을 만들어 줘:
- 리드 양식: 이름, 회사, 전화번호, 소스, 상태
- 고객 양식: 회사명, 업종, 연락처, 담당자
- 상담 양식: 고객 연동, 금액, 단계, 예상 계약일
```

```
IT 자산 관리 앱을 만들어 줘, 기기 정보 등록과 대출/반납 추적이 가능하게
```

```
이 페이지를 공개해서 퍼블릭 접근으로 설정해 줘
```

AI가 앱 생성, 양식 생성, 페이지 공개 등 모든 단계를 자동으로 완료합니다. 명령을 기억할 필요가 없습니다.

## 실제 대화 예시

다음은 전형적인 대화 흐름입니다:

> **사용자**: 직원 휴가 신청 시스템을 만들어 줘
>
> **AI**: 네, 만들어 드리겠습니다. 먼저 환경과 로그인 상태를 확인합니다...
>
> 환경 정상, 로그인 완료. 앱 생성을 시작합니다...
>
> 휴가 신청 시스템이 완성되었습니다! 포함 내용:
> - 휴가 신청 양식 (신청자, 휴가 유형, 시작일/종료일, 사유)
> - 앱 링크: https://www.aliwork.com/APP_XXXXX/...
>
> 승인 프로세스도 추가할까요?

전 과정에서 필요한 것은 요구사항을 말하는 것뿐입니다. AI가 실행을 담당합니다.

## 고급 사용법

익숙해지면 AI에게 더 정확한 지시를 내릴 수 있습니다:

```
「고객 정보」 양식의 필드 목록을 가져와서 필드 설정을 확인하고 싶어
```

```
이 curl 명령을 Yida 커넥터로 만들어 줘:
curl -H "Authorization: Bearer xxx" https://api.example.com/users
```

```
환경에 문제가 없는지 확인해 줘
```

  </Accordion>
