Cursor는 VS Code 기반의 AI 코드 에디터로, 강력한 Agent 모드를 내장하고 있습니다. OpenYida를 설치하면 Agent 모드에서 직접 대화하기만 하면 AI가 Yida 앱을 자동으로 구축합니다.

---

## 초기 설정

<Steps>
  <Step title="Cursor 다운로드">
    [cursor.com](https://cursor.com/)에 방문하여 다운로드 및 설치합니다. macOS / Windows / Linux를 지원합니다.
  </Step>

  <Step title="OpenYida 설치">
    Cursor 내장 터미널(`` Ctrl+` `` 또는 `` Cmd+` ``)을 열고 실행합니다:

    ```bash
    npm install -g openyida
    ```

    스킬팩이 자동으로 주입되며, 추가 설정은 필요 없습니다.
  </Step>

  <Step title="AI에게 Yida 로그인 요청">
    Composer(`Cmd+I`)를 열고 **Agent** 모드로 전환한 후 다음과 같이 말합니다:

    ```
    Yida에 로그인해 줘
    ```

    안내에 따라 QR 코드 스캔 또는 브라우저 로그인을 완료하세요.
  </Step>
</Steps>

## 모델 선택

Cursor의 모델 선택기에서 전환합니다. 권장:

| 모델 | 권장 시나리오 |
|------|----------|
| **Claude Sonnet 4** (권장) | 도구 호출 능력이 강하며, 일상 구축에 최적 |
| **Claude Opus 4** | 복잡한 시스템, 다중 양식 연동 |
| GPT-4o | 간단한 양식, 빠른 응답 |

<Tip>
  AI가 명령을 실행하려면 반드시 **Agent 모드**(Ask 모드가 아닌)를 사용해야 합니다. Composer에서 모드를 Agent로 전환하세요.
</Tip>

## 구축 시작

Agent 모드에서 요구사항을 직접 설명합니다:

```
Yida에서 프로젝트 관리 시스템을 만들어 줘:
- 프로젝트 양식: 프로젝트명, 책임자, 시작일, 종료일, 상태
- 작업 양식: 프로젝트 연동, 작업명, 우선순위, 담당자, 마감일
- 프로젝트 개요 대시보드 페이지 만들어 줘
```

```
회의실 예약 앱을 만들어 줘
```

```
「주문 관리」 앱에 환불 승인 프로세스를 추가해 줘
```

AI가 모든 작업을 자동 실행합니다. 결과를 확인하고 피드백만 주면 됩니다.

## 실제 대화 예시

> **사용자**: 간단한 고객 피드백 수집 시스템을 만들어 줘
>
> **AI**: 만들어 드리겠습니다.
>
> ✓ 앱 「고객 피드백 수집」을 생성했습니다
> ✓ 양식을 생성했습니다: 피드백 유형(제안/불만/문의), 고객명, 연락처, 피드백 내용, 우선순위
> ✓ 앱 링크: https://www.aliwork.com/APP_XXXXX/...
>
> 피드백 통계 대시보드도 추가할까요?

## MCP 모드 (선택적 확장)

인터랙티브 시각화 기능(대시보드 카드, 차트 미리보기 등)이 필요한 경우 MCP를 추가 설정할 수 있습니다. 프로젝트 루트에 `.cursor/mcp.json`을 생성합니다:

```json
{
  "mcpServers": {
    "openyida": {
      "command": "npx",
      "args": ["-y", "@openyida/mcp-app", "--stdio"]
    }
  }
}
```

설정 후 Cursor를 재시작하면 AI 대화 중에 Yida의 차트와 양식 미리보기를 직접 렌더링할 수 있습니다.

<Info>
  MCP는 선택적 확장 기능입니다. MCP를 설정하지 않아도 OpenYida의 모든 핵심 기능(앱 생성, 양식, 페이지, 공개 등)은 정상적으로 사용할 수 있습니다.
</Info>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="AI가 OpenYida를 자동으로 호출하지 않음">
    **Agent 모드**인지 확인하세요. Ask 모드는 질문에만 답할 수 있고, 명령을 실행할 수 없습니다. 또한 대화에서 「Yida」 키워드를 언급하면 AI의 의도 인식에 도움이 됩니다.
  </Accordion>

  <Accordion title="로그인이 만료됨">
    AI에게 「Yida 로그인이 만료된 것 같아, 다시 로그인해 줘」라고 말하세요.
  </Accordion>

  <Accordion title="OpenYida를 업데이트하고 싶음">
    AI에게 「openyida를 최신 버전으로 업데이트해 줘」라고 말하거나 터미널에서 `npm install -g openyida@latest`를 실행하세요.
  </Accordion>
</AccordionGroup>
