Wukong은 DingTalk에 내장된 AI 프로그래밍 어시스턴트입니다. OpenYida는 Wukong과 깊이 통합되어 있으며, 설치 후 대화로 요구사항을 설명하기만 하면 Yida 앱을 구축할 수 있습니다.

---

## 초기 설정

<Steps>
  <Step title="Wukong 워크스페이스 진입">
    DingTalk을 열고 → Wukong 워크스페이스로 진입합니다. Wukong에는 Node.js 런타임이 내장되어 있어 별도 설치가 필요 없습니다.
  </Step>

  <Step title="OpenYida 설치">
    Wukong 터미널에서 실행합니다:

    ```bash
    npm install -g openyida
    ```

    <Warning>
      권한 오류가 표시되면 먼저 Wukong 내장 Node.js 경로를 설정하세요:
      ```bash
      export PATH="$HOME/.real/.bin/node/bin:$PATH"
      npm install -g openyida
      ```
    </Warning>
  </Step>

  <Step title="AI에게 Yida 로그인 요청">
    Wukong 대화 화면에서 직접 말합니다:

    ```
    Yida에 로그인해 줘
    ```

    QR 코드 스캔 방식을 권장합니다. AI가 대화창에 QR 코드를 표시하면 스마트폰의 DingTalk으로 스캔하세요.
  </Step>
</Steps>

---

## 모델 설명

Wukong은 DingTalk 플랫폼이 통합 제공하는 AI 모델을 사용하므로 수동 설정이 필요 없습니다. 모델은 중국어 시나리오와 기업 오피스에 맞게 깊이 최적화되어 있으므로 그대로 사용하면 됩니다.

## 구축 시작

Wukong 대화 화면에서 직접 요구사항을 말합니다:

```
Yida에서 출장 정산 시스템을 만들어 줘:
- 출장 신청: 신청자, 목적, 출발지, 목적지, 날짜
- 경비 정산: 출장 신청 연동, 비용 내역, 금액, 증빙
- 승인 프로세스
```

```
회의실 예약 앱을 만들어 줘
```

```
방금 만든 페이지를 공개 링크로 배포해 줘
```

## 실제 대화 예시

> **사용자**: 주간보고 관리 시스템을 만들어 줘
>
> **AI**: 네, Yida에서 만들겠습니다.
>
> ✓ 앱 「주간보고 관리」를 생성했습니다
> ✓ 「주간보고 제출」 양식을 생성했습니다: 이번 주 완료 사항, 다음 주 계획, 도움 필요 사항, 핵심 지표
> ✓ 앱 링크: https://www.aliwork.com/APP_XXXXX/...
>

## Wukong 특별 참고사항

<Info>
  Wukong 워크스페이스는 샌드박스 환경입니다. 몇 가지 특수한 점이 있습니다:

  - **워크스페이스 경로**: 동적 UUID를 포함합니다(`~/.real/users/{uuid}/workspace/`). OpenYida가 자동으로 인식합니다
  - **파일 초기화**: 처음 사용할 때 AI에게 「Yida 워크스페이스를 초기화해 줘」라고 말하면 자동으로 처리됩니다
  - **명령 타임아웃**: 작업이 오래 걸리는 경우 AI에게 단계별로 실행하도록 할 수 있습니다
</Info>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="npm install에서 권한 오류가 표시됨">
    Wukong 내장 Node.js 경로를 설정한 후 재시도하세요:
    ```bash
    export PATH="$HOME/.real/.bin/node/bin:$PATH"
    npm install -g openyida
    ```
  </Accordion>

  <Accordion title="AI가 Yida 관련 명령을 인식하지 않음">
    설치를 확인하세요: Wukong 터미널에서 `openyida --version`을 실행합니다. 명령이 존재하는데 AI가 트리거하지 않으면 대화에서 명확하게 「Yida」 키워드를 언급하세요.
  </Accordion>

  <Accordion title="로그인 QR 코드가 표시되지 않음">
    AI에게 「QR 코드 스캔 방식으로 Yida에 로그인해 줘」라고 말하세요. AI가 `--agent-qr` 모드로 대화창에 QR 코드를 표시합니다.
  </Accordion>
</AccordionGroup>
