Codex é o ambiente de programação com IA da OpenAI. O OpenYida possui **integração nativa como plugin** no Codex — após a instalação, ele se registra automaticamente como plugin local do Codex, aparecendo diretamente no menu `@` com a entrada "Yida", além de incluir um MCP Server integrado para chamadas de ferramentas. Esta é a integração mais profunda entre todos os IDEs suportados.

---

## Preparação única

<Steps>
  <Step title="Instalar o OpenYida">
    Certifique-se de ter o [Node.js ≥ 18](https://nodejs.org), depois execute:

    ```bash
    npm install -g openyida
    ```

    Após a instalação, automaticamente:
    - O OpenYida é registrado como plugin local do Codex (aparece no menu `@`)
    - O MCP Server é configurado (a IA pode chamar ferramentas do Yida diretamente)
    - O pacote completo de habilidades é injetado
  </Step>

  <Step title="Peça à IA para fazer login no Yida">
    Abra o Codex e diga diretamente:

    ```
    Me ajude a fazer login no Yida
    ```

    A IA abrirá o navegador local para completar o login. Se você pertence a múltiplas organizações, o Codex exibirá um controle de seleção nativo para você escolher.
  </Step>
</Steps>

<Tip>
  Após a instalação, já está pronto para usar. O OpenYida é um "cidadão de primeira classe" no Codex — você nem precisa saber que o CLI existe.
</Tip>

## Modo de uso

### Método 1: Menu @ (Recomendado)

Na caixa de diálogo do Codex, digite `@` e você verá a opção "Yida". Ao clicar, a IA entra automaticamente no modo de desenvolvimento Yida:

```
@Yida Me ajude a criar um sistema de gestão de projetos
```

### Método 2: Conversa direta

Não é necessário usar @. Basta mencionar palavras-chave relacionadas ao "Yida" e a IA usará automaticamente o plugin OpenYida:

```
Construir um sistema de gestão de treinamento de funcionários no Yida, incluindo tabela de cursos, formulário de inscrição e tabela de avaliações
```

## Informações sobre o modelo

O Codex utiliza o modelo integrado da OpenAI, sem necessidade de configuração manual. O modelo oferece excelente suporte para chamadas de ferramentas e geração de código.

## Perguntas frequentes

<AccordionGroup>
  <Accordion title="Não vejo 'Yida' no menu @">
    Confirme que o OpenYida está instalado corretamente: `openyida --version`. Se após a instalação ainda não aparece, reinicie o Codex para que ele reescaneie os plugins. Também é possível verificar manualmente o diretório de plugins:
    ```bash
    ls ~/.openyida/codex-plugin/plugins/openyida/.codex-plugin/plugin.json
    ```
  </Accordion>

  <Accordion title="A seleção de organização não aparece durante o login">
    Se você pertence a apenas uma organização Yida, ela será selecionada automaticamente. O controle de seleção só aparece quando há múltiplas organizações.
  </Accordion>

  <Accordion title="Login expirado">
    Diga à IA "parece que o login no Yida expirou" e ela acionará automaticamente o fluxo de login novamente.
  </Accordion>

  <Accordion title="Atualizar o OpenYida">
    ```bash
    npm install -g openyida@latest
    ```
    Após a atualização, o plugin do Codex também será atualizado automaticamente.
  </Accordion>
</AccordionGroup>
