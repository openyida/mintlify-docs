悟空是釘釘內建的 AI 程式設計助手。OpenYida 與悟空深度適配，安裝後在對話中描述需求即可構建宜搭應用。

---

## 一次性準備

<Steps>
  <Step title="進入悟空工作區">
    打開釘釘 → 進入悟空工作區。悟空自帶 Node.js 執行環境，無需單獨安裝。
  </Step>

  <Step title="安裝 OpenYida">
    在悟空終端中執行：

    ```bash
    npm install -g openyida
    ```

    <Warning>
      如果提示權限錯誤，先配置悟空自帶的 Node.js 路徑：
      ```bash
      export PATH="$HOME/.real/.bin/node/bin:$PATH"
      npm install -g openyida
      ```
    </Warning>
  </Step>

  <Step title="上傳技能包">
    悟空需要手動上傳技能包 zip 檔案（其他 IDE 是自動注入的，悟空例外）。

    1. 前往 [OpenYida Releases](https://github.com/openyida/openyida/releases/latest) 下載最新版本的 **`openyida-skills.zip`**
    2. 在悟空工作區的技能管理頁面，上傳下載好的 zip 檔案

    <Info>
      每次 OpenYida 發布新版本時，建議重新下載並上傳最新的 `openyida-skills.zip`，以獲得最新的宜搭能力支援。
    </Info>
  </Step>

  <Step title="告訴 AI 登入宜搭">
    直接在悟空對話中說：

    ```
    幫我登入宜搭
    ```

    推薦使用掃碼方式 — AI 會在對話框中展示二維碼，用手機釘釘掃碼即可。
  </Step>
</Steps>

## 模型說明

悟空使用釘釘平台統一提供的 AI 模型，無需手動配置。模型針對中文場景和企業辦公做了深度最佳化，直接使用即可。

## 開始構建

在悟空對話中直接說需求：

```
在宜搭上創建一個差旅報銷系統：
- 出差申請：申請人、目的、出發地、目的地、日期
- 費用報銷：關聯出差申請、費用明細、金額、憑證
- 審批流程
```

```
幫我搭一個會議室預約應用
```

```
把剛才創建的頁面發佈成公開連結
```

## 悟空特別說明

<Info>
  悟空工作區是沙箱環境，有幾個特殊點值得了解：

  - **工作區路徑**：包含動態 UUID（`~/.real/users/{uuid}/workspace/`），OpenYida 會自動識別
  - **檔案初始化**：第一次使用時告訴 AI「初始化宜搭工作區」，它會自動處理
  - **命令逾時**：如果某個操作較慢，可以讓 AI 分步執行
</Info>

## 常見問題

<AccordionGroup>
  <Accordion title="npm install 提示權限錯誤">
    配置悟空自帶的 Node.js 路徑後重試：
    ```bash
    export PATH="$HOME/.real/.bin/node/bin:$PATH"
    npm install -g openyida
    ```
  </Accordion>

  <Accordion title="AI 不識別宜搭相關指令">
    確認安裝成功：在悟空終端運行 `openyida --version`。如果命令存在但 AI 不觸發：

    1. 在對話中明確提及「宜搭」關鍵詞
    2. 檢查悟空內建的「應用開發」技能是否與 OpenYida 衝突 — 悟空自帶的應用開發技能可能權重更高，導致 AI 優先使用它而非 OpenYida。如果不需要內建技能，可以在悟空技能管理頁面將其停用。
  </Accordion>

  <Accordion title="登入二維碼不顯示">
    告訴 AI：「用掃碼方式登入宜搭」。AI 會使用 `--agent-qr` 模式在對話框中展示二維碼。
  </Accordion>

  <Accordion title="如何更新技能包">
    前往 [OpenYida Releases](https://github.com/openyida/openyida/releases/latest) 下載最新 `openyida-skills.zip`，重新上傳到悟空技能管理頁面即可。
  </Accordion>
</AccordionGroup>
