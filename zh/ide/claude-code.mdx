Claude Code 是 Anthropic 推出的终端 AI 助手。安装 OpenYida 后，你只需和 AI 对话，它会自动调用所有命令帮你完成应用构建。

---

## 一次性准备

整个过程只需要两步，之后就可以纯对话操作了。

<Steps>
  <Step title="安装 OpenYida">
    确保已有 [Node.js ≥ 18](https://nodejs.org)，然后在终端运行：

    ```bash
    npm install -g openyida
    ```

    安装完成后，OpenYida 的技能包会自动注入 Claude Code，无需其他配置。
  </Step>

  <Step title="告诉 AI 登录宜搭">
    启动 Claude Code，直接说：

    ```
    帮我登录宜搭
    ```

    AI 会自动调用登录命令，打开浏览器或展示二维码让你扫码。登录一次后凭证会缓存，后续无需重复操作。
  </Step>
</Steps>

<Tip>
  就这样，准备完成了。接下来你只需要和 AI 对话就好。
</Tip>

---

## 模型选择

Claude Code 默认使用 Claude 系列模型，可通过 `/model` 命令切换：

| 模型 | 推荐场景 |
|------|----------|
| **Claude Sonnet 4**（默认） | 日常应用构建，速度快 |
| **Claude Opus 4** | 复杂多表单业务系统 |

两者都能很好地驱动 OpenYida，日常使用 Sonnet 即可。

## 开始构建

直接用自然语言描述你想要的应用，AI 会全程自动处理：

```
帮我在宜搭上创建一个 CRM 系统，包含：
- 线索表单：姓名、公司、电话、来源、状态
- 客户表单：公司名称、行业、联系人、客户经理
- 商机表单：关联客户、金额、阶段、预计成交日期
```

```
创建一个 IT 资产管理应用，能录入设备信息、跟踪领用归还
```

```
把这个页面发布出去，设置为公开访问
```

AI 会自动完成创建应用、创建表单、发布页面等所有步骤，你不需要记任何命令。

## 实际对话示例

以下是一次典型的对话流程：

> **你**：帮我创建一个员工请假系统
>
> **AI**：好的，我来帮你创建。先检查一下环境和登录状态...
>
> 环境正常，已登录。现在开始创建应用...
>
> 请假系统已创建完成！包含：
> - 请假申请表单（申请人、请假类型、开始/结束日期、原因）
> - 应用链接：https://www.aliwork.com/APP_XXXXX/...
>
> 需要我继续添加审批流程吗？

你全程只需要说需求，AI 负责执行。

## 进阶用法

当你更熟悉后，可以给 AI 更精确的指令：

```
获取「客户信息」表单的字段列表，我想确认一下字段配置
```

```
帮我把这个 curl 命令创建成宜搭连接器：
curl -H "Authorization: Bearer xxx" https://api.example.com/users
```

```
检查一下环境有没有问题
```

## 常见问题

<AccordionGroup>
  <Accordion title="AI 说找不到 openyida 命令">
    在终端中确认安装成功：`openyida --version`。如果已安装但 Claude Code 找不到，退出重新启动 Claude Code。
  </Accordion>

  <Accordion title="登录过期了怎么办">
    直接告诉 AI「重新登录宜搭」，它会自动处理。
  </Accordion>

  <Accordion title="AI 没有使用 OpenYida 技能">
    在对话中提及「宜搭」关键词即可触发。例如「在宜搭上创建一个表单」。
  </Accordion>

  <Accordion title="想更新到最新版本">
    告诉 AI「帮我更新 openyida」，或手动运行 `npm install -g openyida@latest`。
  </Accordion>
</AccordionGroup>
