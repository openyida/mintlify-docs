Visual Studio Code 通过 GitHub Copilot Chat 的 Agent 模式支持工具调用。配置 MCP 后，你可以在 VS Code 中用自然语言对话构建宜搭应用。

---

## 一次性准备

<Steps>
  <Step title="安装 GitHub Copilot Chat">
    在 VS Code 扩展市场搜索并安装 **GitHub Copilot** 和 **GitHub Copilot Chat**。需要 GitHub Copilot 订阅。
  </Step>

  <Step title="安装 OpenYida">
    打开 VS Code 终端（`` Ctrl+` ``），运行：

    ```bash
    npm install -g openyida
    ```
  </Step>

  <Step title="配置 MCP">
    在项目根目录创建 `.vscode/mcp.json`：

    ```json
    {
      "servers": {
        "openyida": {
          "command": "npx",
          "args": ["-y", "@openyida/mcp-app", "--stdio"]
        }
      }
    }
    ```

    重新加载 VS Code（`Cmd+Shift+P` → "Reload Window"）。
  </Step>

  <Step title="告诉 AI 登录宜搭">
    打开 Copilot Chat，切换到 Agent 模式，说：

    ```
    帮我登录宜搭
    ```
  </Step>
</Steps>

<Info>
  VS Code 的 Copilot Chat 需要通过 MCP 来调用 OpenYida 工具。这和 Cursor、Claude Code 不同（它们通过技能包自动集成）。
</Info>

## 模型选择

在 Copilot Chat 面板点击模型选择器切换：

| 模型 | 推荐场景 |
|------|----------|
| **Claude Sonnet 4**（推荐） | 工具调用最稳定 |
| GPT-4o | 响应快，简单任务 |
| Claude Opus 4 | 复杂任务（需 Copilot Pro+） |

## 开始构建

在 Copilot Chat 的 Agent 模式中对话：

```
在宜搭上帮我创建一个报销管理系统：
- 报销申请表单：申请人、费用类型、金额、事由、附件
- 审批流程：部门经理审批
```

```
创建一个会议纪要应用，可以记录会议主题、参会人、决议事项
```

```
查一下我宜搭上有哪些应用
```

AI 会通过 MCP 工具自动完成操作。

## 实际对话示例

> **你**：帮我创建一个简单的图书借阅系统
>
> **AI**：我来通过 OpenYida 帮你创建。
>
> ✓ 已创建应用「图书借阅管理」
> ✓ 已创建「图书信息」表单：书名、作者、ISBN、分类、库存数量
> ✓ 已创建「借阅记录」表单：关联图书、借阅人、借出日期、归还日期
>
> 需要我添加一个图书查询的展示页面吗？

## 常见问题

<AccordionGroup>
  <Accordion title="Copilot Chat 中没有 Agent 模式">
    需要 VS Code 1.99+ 和最新版 Copilot Chat 扩展。更新后重启 VS Code。
  </Accordion>

  <Accordion title="AI 没有使用 OpenYida 工具">
    确认 `.vscode/mcp.json` 配置正确且已重新加载窗口。在对话中明确提及「宜搭」或「openyida」帮助 Agent 识别意图。
  </Accordion>

  <Accordion title="MCP Server 启动失败">
    在终端测试：`npx @openyida/mcp-app --stdio`。如果报错，通常是 Node.js 版本过低，需升级到 18+。
  </Accordion>
</AccordionGroup>
