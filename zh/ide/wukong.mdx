悟空是钉钉内置的 AI 编程助手。OpenYida 与悟空深度适配，安装后在对话中描述需求即可构建宜搭应用。

---

## 一次性准备

<Steps>
  <Step title="进入悟空工作区">
    打开钉钉 → 进入悟空工作区。悟空自带 Node.js 运行时，无需单独安装。
  </Step>

  <Step title="安装 OpenYida">
    在悟空终端中运行：

    ```bash
    npm install -g openyida
    ```

    <Warning>
      如果提示权限错误，先配置悟空自带的 Node.js 路径：
      ```bash
      export PATH="$HOME/.real/.bin/node/bin:$PATH"
      npm install -g openyida
      ```
    </Warning>
  </Step>

  <Step title="上传技能包">
    悟空需要手动上传技能包 zip 文件（其他 IDE 是自动注入的，悟空例外）。

    1. 前往 [OpenYida Releases](https://github.com/openyida/openyida/releases/latest) 下载最新版本的 **`openyida-skills.zip`**
    2. 在悟空工作区的技能管理页面，选择「新技能」→「上传技能」
    3. 上传下载好的 zip 文件，勾选识别出的 `openyida` 技能并创建；如果提示已存在同名技能，勾选后会覆盖安装

    <Info>
      每次 OpenYida 发布新版本时，建议重新下载并上传最新的 `openyida-skills.zip`，以获得最新的宜搭能力支持。
    </Info>
  </Step>

  <Step title="告诉 AI 登录宜搭">
    在对话框点击「技能」，选择 `openyida` 后再发送登录指令：

    直接在悟空对话中说：

    ```
    帮我登录下宜搭
    ```

    登录成功后，AI 会返回当前组织、用户、域名，并提示「已登录，可直接使用宜搭」。
  </Step>
</Steps>

## 图形化上传与登录

如果你在悟空界面里操作，按下面的截图流程走一遍即可。

### 上传 OpenYida 技能

1. 在悟空左侧或技能页进入「我的技能」，点击右上角「新技能」，选择「上传技能」。

![在悟空我的技能页选择上传技能](/images/wukong/openyida-upload-skill-menu.png)

2. 选择下载好的 `openyida-skills.zip`。上传后，弹窗会识别出 `openyida` 技能；勾选它，再点击「创建技能」。

![上传 openyida-skills.zip 并勾选 openyida 技能](/images/wukong/openyida-upload-confirm.jpg)

<Info>
  如果弹窗提示「已存在同名技能，勾选后将覆盖安装」，通常表示你之前已经装过 OpenYida。需要更新技能包时，勾选 `openyida` 后继续创建即可。
</Info>

### 避免内置技能抢占

悟空内置的「应用开发」技能也能响应“开发应用”类需求。为了让宜搭登录、建应用、建表单等指令稳定走 OpenYida，建议在不需要内置技能时打开「应用开发」技能详情，点击右上角「禁用」。

![禁用悟空内置应用开发技能](/images/wukong/openyida-disable-app-dev-skill.jpg)

### 在对话中选择 openyida 并登录

1. 回到悟空首页，在输入框下方点击「技能」。
2. 在技能列表中选择 `openyida`；找不到时，点击底部「探索和管理技能」进入技能页确认是否已上传。

![从悟空对话框的技能列表进入探索和管理技能](/images/wukong/openyida-skill-menu-manage.jpg)

![在悟空对话框中选择 openyida 技能](/images/wukong/openyida-select-skill.jpg)

3. 看到输入框左上方出现 `openyida` 标签后，发送：

```text
帮我登录下宜搭
```

登录成功时，回复里会显示组织、用户和域名，后续就可以继续创建应用、表单或页面。

![悟空中使用 openyida 登录宜搭成功](/images/wukong/openyida-login-success.jpg)

## 模型说明

悟空使用钉钉平台统一提供的 AI 模型，无需手动配置。模型针对中文场景和企业办公做了深度优化，直接使用即可。

## 开始构建

在悟空对话中直接说需求：

```
在宜搭上创建一个差旅报销系统：
- 出差申请：申请人、目的、出发地、目的地、日期
- 费用报销：关联出差申请、费用明细、金额、凭证
- 审批流程
```

```
帮我搭一个会议室预约应用
```

```
把刚才创建的页面发布成公开链接
```

## 悟空特别说明

<Info>
  悟空工作区是沙箱环境，有几个特殊点值得了解：

  - **工作区路径**：包含动态 UUID（`~/.real/users/{uuid}/workspace/`），OpenYida 会自动识别
  - **文件初始化**：第一次使用时告诉 AI「初始化宜搭工作区」，它会自动处理
  - **命令超时**：如果某个操作较慢，可以让 AI 分步执行
</Info>

## 常见问题

<AccordionGroup>
  <Accordion title="npm install 提示权限错误">
    配置悟空自带的 Node.js 路径后重试：
    ```bash
    export PATH="$HOME/.real/.bin/node/bin:$PATH"
    npm install -g openyida
    ```
  </Accordion>

  <Accordion title="AI 不识别宜搭相关指令">
    确认安装成功：在悟空终端运行 `openyida --version`。如果命令存在但 AI 不触发：

    1. 在对话中明确提及「宜搭」关键词
    2. 检查悟空内置的「应用开发」技能是否与 OpenYida 冲突 — 悟空自带的应用开发技能可能权重更高，导致 AI 优先使用它而非 OpenYida。如果不需要内置技能，可以在悟空技能管理页面将其禁用。
  </Accordion>

  <Accordion title="登录二维码不显示">
    告诉 AI：「用扫码方式登录宜搭」。AI 会使用 `--agent-qr` 模式在对话框中展示二维码。
  </Accordion>

  <Accordion title="如何更新技能包">
    前往 [OpenYida Releases](https://github.com/openyida/openyida/releases/latest) 下载最新 `openyida-skills.zip`，重新上传到悟空技能管理页面即可。
  </Accordion>
</AccordionGroup>
